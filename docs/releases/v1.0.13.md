# LiteLauncher v1.0.13 Release Notes

Release date: 2026-04-24

## Highlights

- Added File Hash plugin (`webtools-file-hash`) for `MD5 / SHA1 / SHA256 / SHA512` calculation, expected-hash verification, and copyable output.
- Added Port Helper plugin (`webtools-port-helper`) for port / PID lookup, process ownership inspection, and occupied-process termination.
- Enhanced Hardware Inspector with richer detail output and Markdown / HTML report workflows.

## UX and Fixes

- Switched File Hash file selection to a native main-process file dialog for stable absolute path selection.
- Prevented launcher auto-hide while native file selection is active.
- Improved Port Helper PID feedback so "process exists but has no active sockets" is distinct from true no-match states.
- Avoided unwanted PID input autofill after Port Helper query actions.
- Continued plugin panel robustness and style alignment work.

## Build and Release

- Version bumped to `1.0.13`.
- Desktop packages published via GitHub Actions for Windows and macOS.
