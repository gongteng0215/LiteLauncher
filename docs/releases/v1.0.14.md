# LiteLauncher v1.0.14 Release Notes

Release date: 2026-05-12

## Highlights

- Added Image Prompt plugin (`webtools-image-prompt`) for ChatGPT Images 2.0 prompt generation.
- Added 26 switchable style presets and 12 smart scene templates for ecommerce, brand key visuals, social covers, short-video covers, birthdays, food, SaaS, movies, travel, medical, finance, and portrait-style scenes.
- Made the prompt builder more scene-aware: subject, style, composition, lighting, material/detail, environment, mood, text, and constraints now move together instead of exposing one oversized option list.
- Added structured birthday photo fields for age, title, subtitle, name, and label, so birthday prompts can place a real photo/person and write the correct birthday text.
- Tightened the search home layout so Recent, Pinned, and Plugins use the same compact adaptive card style with fixed-size icons and two-line titles.

## Image Prompt

- Generates commercial-ready prompt text from linked module selections instead of requiring every field to be typed manually.
- Supports ChatGPT Images 2.0 as the current product target while keeping the builder extensible for future image products.
- Adds 25 scene-aware text design presets with typography, color, effect, layout, safe-area, and keyword metadata.
- Recommends text position and type style by scene, such as bottom movie titles, top-left SaaS headings, premium travel wordmarks, and quiet portrait captions.
- Writes text hierarchy, color, effect, layout, safe area, and birthday structure into the generated prompt so typography is treated as part of the composition.
- Refreshes text controls when smart templates are selected, including EXACT copy, position, typography style, text design, and structured birthday fields.
- Adds visible copy feedback after copying the generated prompt.
- Adds shared prompt-builder regression coverage for style/template state, text design output, birthday fields, and cross-style generation.

## Renderer and Search UI

- Moved Image Prompt generation into `src/shared/image-prompt-builder.ts` and registered the new plugin through the main plugin system.
- Kept the Image Prompt panel implementation inside `plugin-panel-impls.ts`, with source regressions to prevent new default plugin panels from drifting back into `renderer.ts`.
- Continued renderer panel consolidation by routing File Hash, Port Helper, Markdown, Diff, Config, SQL, Password, JSON, URL, Timestamp, Cron, Strings, Colors, QRCode, UA, API, and HTTP Mock paths through the shared panel implementation registry.
- Added a keepOpen refresh guard so opening a plugin command is not overwritten by a second search-list refresh.
- Added source-level layout regression coverage for the compact search section grid.

## Documentation and Baseline Sync

- Bumped the project baseline to `v1.0.14`.
- Updated README, PRD, task list, plugin development spec, Cashflow docs, WebTools parity checklist, migration plan, and work log.
- Documented the Image Prompt plugin, smart templates, birthday fields, text design cards, scene-specific text recommendations, and copy feedback.
- Kept `v1.0.13` release notes aligned with the already-published GitHub Release and moved the new Image Prompt work to this `v1.0.14` release.

## Quality

  - `pnpm run check:encoding`
