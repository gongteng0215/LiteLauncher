# LiteLauncher v1.0.15 Release Notes

Release date: 2026-05-12

## Hotfix

- Fixed upgrade migration for existing users whose saved visible-plugin list came from an older version.
- `webtools-image-prompt` is now added to the required default-visible plugin migration list, so the Image Prompt plugin appears after upgrading instead of being hidden by the old local whitelist.
- Updated the app-level current default visible plugin list to include `webtools-image-prompt`.

## Quality

- Added a regression test that checks startup visible-plugin migration includes Image Prompt as a new default.
- Verified the targeted regression:
  - `pnpm run build`
  - `node dist/test/visible-plugins-regression.test.js`
