# LiteLauncher v1.0.16 Release Notes

Release date: 2026-05-28

## Highlights

- Continued the renderer decomposition work so `src/renderer/renderer.ts` acts more like an orchestration shell while plugin and standalone panel logic stays in `src/renderer/plugin-panel-impls.ts`.
- Reconciled and landed the usable round 2 narrow-window / high-DPI panel baseline work on `main`, including the compact panel layout smoke coverage.
- Brought the `Image Base64`, `Clipboard Workbench`, `Hardware Inspector`, and broader WebTools panel structure follow-up changes into the mainline together with stronger regression guardrails.

## Quality

- Added source-level regression coverage to keep `openPanel` routing and panel-mode keydown dispatch out of large inline renderer handlers.
- Extended plugin panel regression coverage to `53` source assertions.
- Verified the full release gate:
  - `pnpm run test:regression:full`

## Notes

- GitHub already contains `v1.0.15`, so this release advances the app version and tag to `v1.0.16`.
