# LiteLauncher v1.0.17 Draft Release Notes

Release date: TBD

## Highlights

- Unified Windows Store application identities across catalog indexing and dynamic command search, so `StartApps / WindowsApps` results keep the same stable `app:startapp:*` item ids whether the PATH alias is available or not.
- Closed the remaining Microsoft Store `Codex` pinning regression path and generalized the fix so the same mismatch does not reappear for similar Store apps.
- Improved pin feedback across the stack: the launcher now reports clearer pin failure reasons, and the settings error log surfaces readable summaries for pin-related failures.

## Quality

- Added regression coverage for catalog/dynamic-search Windows Store id consistency, structured pin result status text, renderer-side readable pin error log formatting, and renderer preference for stable `app:startapp:*` results.
- Verified the live Electron interaction path with the targeted search-home smoke, including successful `setItemPinned(...)` results inside the real shell.
