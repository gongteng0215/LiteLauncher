# LiteLauncher v1.0.20 发布日志

发布日期：2026-06-04

## 更新亮点

- 修复了启动器置顶不稳定的问题。窗口显示后会再次确认置顶状态，并在短延迟下补做恢复，降低“有时能置顶、有时失败”的概率。
- 设置页的错误日志现在会优先高亮置顶相关诊断，例如“置顶状态掉线”“显示后快速失焦”“恢复重试后仍异常”，排查会更直观。
- 自动更新链路继续收口。Windows NSIS 安装版的安装包名称与 `latest.yml` 现已严格对齐，降低线上更新识别失败的风险。
- macOS 打包版补齐了更新元数据链路与设置页展示，更新卡片会显示当前版本、目标版本和发布说明。
- 密码工具布局继续压紧，输入区与结果区更整齐，生成结果一屏能看到更多内容。

## 稳定性改进

- 搜索输入的键盘触发规则更稳：正常输入、回退、删除仍会正确触发搜索，方向键等导航按键不再造成多余刷新。
- 动态搜索结果的置顶行为更稳，结果刷新后会按稳定 `itemId` 重新定位，减少“能搜到但置顶失败”的情况。
- 设置页更新卡片补充了更完整的状态信息，便于确认当前版本、目标版本和是否已附带发布说明。
- 为置顶恢复、设置页错误日志高亮、桌面更新元数据、mac 发布链路补了新的源码回归与 Electron 定向 smoke。
