# LiteLauncher v1.0.21 Release Notes

Release date: 2026-06-04

## Highlights

- Hardened pinning for live search results: stale right-click pin actions now relocate by `itemId` after list refresh, and temporary live-result identities no longer leak into the persisted catalog.
- Tightened keyboard-driven search refresh behavior: typing, backspace, and delete continue to debounce correctly in search mode, while navigation keys no longer trigger redundant refreshes.
- Expanded CodeAgent Switch for the current Codex config model: Root fields can now be edited and previewed directly, legacy embedded profiles can migrate to standalone files, and current config source details stay visible in the panel.
- Finished the current desktop release/update hardening batch: release outputs are cleaned before packaging, updater metadata is verified, GitHub Releases stay visible to the auto-update client, the Windows NSIS artifact name now stays aligned with `latest.yml`, and packaged macOS builds now follow the same updater metadata path.
- Polished the Password tool layout with tighter controls, aligned inputs, and denser result rows so more generated entries stay visible in the panel.
- Improved launcher topmost stability: showing the launcher now re-asserts always-on-top after display, retries the recovery pulse, and keeps focused smoke coverage around hide/show recovery.
- Added launcher topmost diagnostics in Settings: the error log now highlights topmost-loss / blur-after-show events in a compact summary card before the raw log output.
- Added focused regression coverage around search, pinning, CodeAgent Switch, updater/release paths, launcher topmost recovery, and settings error-log rendering to keep this release batch stable.

## Quality

- Kept `src/renderer/renderer.ts` as a script instead of a module, avoiding the global-sharing regression that broke `plugin-panel-impls.ts` during the pinning follow-up.
- Added regression checks for hydrated Windows app alias pin requests, stale pin relocation after result refresh, keyboard-aware search debounce rules, CodeAgent Switch Root/profile flows, desktop release metadata verification, launcher topmost diagnostics, and compact settings error-log highlights.
- The updater settings card now surfaces current version, target version, and release notes so update state is easier to verify before shipping.
- Verified this release batch with targeted build checks, focused Electron smoke coverage, and a local Windows packaging pass.
