# LiteLauncher v1.0.22 Release Notes

Release date: 2026-06-10

## Highlights

- Continued the CodeAgent Switch transition to the new config-group model: current config, group list, and detail editing are now easier to distinguish, and the empty state can create a group directly from the live config.
- Added a separate display name for config groups, so the UI can show a readable label while the stable `ID` still drives filenames and switching.
- Clarified the `Current Provider / Key` entry point so jumping from the active config into the underlying provider editor is easier to understand.
- Hardened Windows provider-key writes by switching to an encoded PowerShell script path, allowing API keys with characters like `$`, `'`, and `&` to be written safely into the user environment.
- Updated the copyable provider-key command to use the same safe PowerShell script instead of interpolating raw secrets into a command snippet.
- Moved desktop startup through `scripts/start-electron.cjs`, which sanitizes `ELECTRON_RUN_AS_NODE` and launches Electron in a safer detached Windows flow.

## Quality

- CodeAgent Switch now surfaces clearer active-provider context when a config group is using a provider underneath the current live config.
- Config-group list rows now prefer the display name and only fall back to the internal `ID` when no name is set.
- Added regression coverage for provider-key writes, config-group naming, current-config panel flows, release metadata versioning, and the new Electron start helper.
