# LiteLauncher v1.0.22 发布日志

发布日期：2026-06-10

## 更新亮点

- CodeAgent Switch 继续收口到“配置组”模型：当前配置卡、配置组列表和右侧详情的层级更清楚，空状态下也可以直接“从当前配置生成配置组”。
- 配置组新增独立“配置名”，现在可以用更易懂的中文名展示，`ID` 继续保留给文件名和内部切换使用。
- `当前 Provider / Key` 入口更明确，当前配置跳转到底层 Provider 详情后，不会再和配置组编辑页混在一起。
- Windows 下写入 Provider API Key 改成安全的 PowerShell 编码脚本，包含 `$`、`'`、`&` 等特殊字符的 Key 也能稳定写入用户环境变量。
- 复制出来的 Key 设置命令也同步改成安全脚本，不再把明文值直接拼进 PowerShell 片段。
- 启动流程切到独立的 `start-electron.cjs`，会自动清理 `ELECTRON_RUN_AS_NODE` 并在 Windows 下用后台分离方式拉起 Electron，减少启动异常。

## 稳定性与体验

- CodeAgent Switch 的 Provider / 配置组关系提示更清楚，当前生效配置使用的底层 Provider 会在详情页直接说明。
- 配置组列表现在优先显示“配置名”，没有配置名时才回退显示 `ID`。
- 针对 Key 写入、配置组命名、当前配置入口和启动脚本补齐了新的回归测试，降低后续改动把这些链路带坏的风险。
