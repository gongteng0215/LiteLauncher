# LiteLauncher v1.0.23 Release Notes

Release date: 2026-06-10

## Highlights

- Fixed the GitHub Actions macOS release path so tag builds no longer fail during preflight when Apple signing secrets are unavailable; the workflow now continues with unsigned macOS installer and updater assets.
- Kept the signed packaging path intact for repositories that do provide Apple signing secrets, so the workflow still upgrades cleanly to signed builds later.
- Added workflow-source regression coverage for this fallback behavior to prevent future tag releases from being blocked by missing optional signing inputs.

## Reliability

- `v1.0.23` is primarily a release-pipeline stability update; desktop app functionality is unchanged from `v1.0.22`.
- This version is intended to restore complete Windows + macOS GitHub Release asset publishing from the standard tag workflow.

## Verification

- `pnpm run typecheck`
- `pnpm run build`
- `node dist/test/build-desktop-workflow-source.test.js`
- `node dist/test/launcher-main-flow-regression.test.js`
- `pnpm run dist:win`

## Notes

- This release advances the app version from `v1.0.22` to `v1.0.23`.
- If Apple signing secrets are added later, the workflow will still prefer signed macOS packaging; when they are absent, it now falls back to unsigned macOS release assets instead of failing the whole tag release.
