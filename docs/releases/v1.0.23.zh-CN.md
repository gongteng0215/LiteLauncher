# LiteLauncher v1.0.23 发布日志

发布日期：2026-06-10

## 更新亮点

- 修复 GitHub Actions 的 macOS 发布链路：标签发布时如果没有 Apple 签名 secrets，不再在预检阶段直接失败，而是继续构建 unsigned macOS 安装包和 updater 资产。
- 保留有签名 secrets 时的签名路径，后续补齐 Apple 证书后仍可无缝回到签名打包。
- 为这条回退逻辑补充了 workflow 源码回归测试，避免后续再把“无 secrets 直接中断 tag 发布”带回来。

## 稳定性与发布

- `v1.0.23` 主要是发布与打包稳定性修复，桌面应用功能与 `v1.0.22` 保持一致。
- 这次版本用于恢复完整的 Windows + macOS GitHub Release 资产发布链路。

## 已验证

- `pnpm run typecheck`
- `pnpm run build`
- `node dist/test/build-desktop-workflow-source.test.js`
- `node dist/test/launcher-main-flow-regression.test.js`
- `pnpm run dist:win`

## 说明

- 本次版本号为 `v1.0.23`，上一版线上发布为 `v1.0.22`。
- 如果后续补齐 Apple 签名相关 secrets，workflow 仍会优先走签名构建；当前未配置时则自动回退到 unsigned macOS 发布资产。
