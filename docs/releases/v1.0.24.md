# LiteLauncher v1.0.24 Release Notes

Release date: 2026-06-10

## Highlights

- Automatic updates no longer check only once after launch: the app now performs an initial automatic check about 12 seconds after startup and keeps rechecking every 2 hours while the app stays open.
- Update handling after discovery is unchanged: new versions still download automatically and install on app quit once the package is ready.
- Added a small concurrency guard so manual update checks and background timed checks do not overlap.

## Reliability

- Added source-level regression coverage for updater scheduling and folded it into the regular `test:regression` path, reducing the chance of regressing back to a one-shot startup-only check.
- Desktop app functionality is otherwise unchanged from `v1.0.23`; this release is focused on improving the auto-update experience.

## Verification

- `pnpm run build`
- `node dist/test/app-updater-source.test.js`
- `node dist/test/launcher-main-flow-regression.test.js`
- `pnpm run dist:win`

## Notes

- This release advances the app version from `v1.0.23` to `v1.0.24`.
- Automatic updates still apply only to Windows NSIS installs and packaged macOS builds; Portable builds remain manual-update only.
