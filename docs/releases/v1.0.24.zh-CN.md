# LiteLauncher v1.0.24 发布日志

发布日期：2026-06-10

## 更新亮点

- 自动更新现在不再只在启动后检查一次：应用启动约 12 秒后会先自动检查一轮，随后在应用持续运行期间每 2 小时自动复查一次。
- 发现新版本后的行为保持不变：仍然会自动下载更新包，下载完成后在退出应用时自动安装。
- 增加了更新检查并发保护，避免手动点击“检查更新”和后台定时检查撞在一起。

## 稳定性与体验

- 补充了自动更新调度源码回归测试，并接入常规 `test:regression` 链路，后续改动更容易及时发现“只启动检查、不定时复查”这类回退。
- 桌面应用主功能与 `v1.0.23` 保持一致，这次版本主要聚焦自动更新体验补强。

## 已验证

- `pnpm run build`
- `node dist/test/app-updater-source.test.js`
- `node dist/test/launcher-main-flow-regression.test.js`
- `pnpm run dist:win`

## 说明

- 本次版本号为 `v1.0.24`，上一版线上发布为 `v1.0.23`。
- 自动更新仍仅支持 Windows NSIS 安装版与 macOS 打包版，Portable 版依旧不支持自动更新。
