# LiteLauncher v1.0.25 Release Notes

Release date: 2026-06-17

## Fixes

- Fixed raw HTML tags appearing in the Settings update notes area. GitHub Release notes containing elements such as `<h1>`, `<ul>`, `<li>`, and `<code>` now render as constrained rich text with compact Settings styling.
- Fixed intermittent pin failures for dynamic Windows app results such as `Codex`. Windows Store / StartApps / PATH alias items can now be pinned, persisted, and resolved again in the pinned section instead of being rejected as stale results.

## Reliability

- Update notes rendering now allows only common release-note tags and restricts link protocols before inserting rich content into the Settings page.
- Pinned item normalization now accepts items that are either present in the static catalog or dynamically resolvable, covering dynamic IDs such as `app:startapp:*` and `app:path-alias:*`.
- Added regression coverage so update notes do not fall back to literal text rendering and dynamic app pins are not removed by static catalog cleanup.
