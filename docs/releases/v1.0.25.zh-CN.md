# LiteLauncher v1.0.25 发布日志

发布日期：2026-06-17

## 修复

- 修复设置页自动更新说明显示原始 HTML 标签的问题。GitHub Release 返回的 `<h1>`、`<ul>`、`<li>`、`<code>` 等内容现在会按受限富文本渲染，并保留紧凑的设置页样式。
- 修复 `Codex` 等 Windows Store / StartApps / PATH alias 动态应用偶发置顶失败的问题。动态解析出来的应用现在可以正常置顶、保存，并在置顶列表中重新解析显示，不会再被误判为“当前结果已过期”。

## 稳定性

- 更新说明渲染现在只允许常见发布日志标签，并限制链接协议，避免直接把 Release HTML 无约束写入设置页。
- 置顶 ID 清洗规则改为识别“静态 catalog 或动态可重新解析”的项目，覆盖 `app:startapp:*` 与 `app:path-alias:*` 这类动态应用 ID。
- 补齐源码回归，防止更新说明再次退回纯文本渲染，或动态应用置顶再次被静态 catalog 清洗误删。
