# LiteLauncher v1.0.26 Release Notes

Release date: 2026-06-18

## Highlights

- The Settings updater card now surfaces more actionable diagnostics, including current version, target version, auto-update state, and the latest updater phase.
- The Settings error log area now includes a copy action, while pin failures and topmost-window issues are promoted into compact summary cards.
- `plugin`, `settings`, and `cashflow` panels now stay open after launcher blur and only close through `Esc`, back navigation, or explicit hide flows.
- `search` mode still follows the launcher-style blur-to-hide behavior so the quick-open workflow stays lightweight.

## Reliability

- Preserved end-to-end updater verification evidence: a live `v1.0.24` client was verified to detect `v1.0.25`, load release notes, and finish downloading the update.
- Added real-blur E2E coverage for panel persistence so blur-policy tests no longer pass only because `E2E_MODE` bypassed the main-process blur handler.
- Added an opt-in real blur handling flag to the E2E launch helper, keeping focused window-policy tests realistic without destabilizing unrelated smoke coverage.
