# LiteLauncher v1.0.26 发布日志

发布日期：2026-06-18

## 本版重点

- 设置页“自动更新”卡片补齐了更可排查的诊断信息，包含当前版本、目标版本、自动更新是否启用和最近阶段。
- 设置页错误日志区新增“复制日志”入口，置顶失败和窗口置顶异常会优先显示为摘要卡，方便先看结论再看原始日志。
- `plugin / settings / cashflow` 面板现在失焦后不会立刻消失，只会通过 `Esc`、返回按钮或显式隐藏流程退出。
- `search` 模式仍保持 launcher 式失焦自动隐藏，避免影响快速调起和快速收起的主流程体验。

## 稳定性

- 补齐了自动更新真实链路验证记录：已确认线上 `v1.0.24` 客户端可以发现 `v1.0.25`、读取发布日志并完成下载。
- 面板失焦行为新增真实 blur E2E 护栏，避免测试环境因为 `E2E_MODE` 短路而出现“测试通过但没测到主进程策略”的假阳性。
- E2E 启动工具新增可显式开启真实 blur 处理的开关，只有需要验证窗口隐藏策略的 smoke 才开启，降低对其他 E2E 稳定性的影响。

## 发布前检查

- 复核 GitHub Release 资产包含 Windows NSIS 安装包、zip、`latest.yml`，以及 macOS 对应资产和 `latest-mac.yml`
- 至少用一台真实客户端复核一次“检查更新 -> 读取发布日志 -> 下载完成”链路
- 确认本版标签、安装包文件名和自动更新元数据中的版本号都对齐 `v1.0.26`
