# LiteLauncher v1.0.27 Release Notes

Release date: 2026-06-26

## Highlights

This release introduces the **LiteSnap screenshot and pin** plugin with a first Snipaste-like experience, plus a Windows native GDI capture addon for faster capture.

### LiteSnap Capture

- Default shortcut `F1` enters full-screen capture with region selection, drag-to-adjust, double-click copy, and save-to-disk.
- Windows native GDI capture addon improves F1 startup and grab speed, with automatic Electron fallback when native capture is unavailable.
- Window auto-detection on hover with click-to-select.
- Magnifier and color picker for precise region selection.

### Annotation Tools

- Icon toolbar: rectangle, ellipse, line, arrow, pen, highlighter, text, numbering, mosaic, and blur.
- Undo / redo / delete, plus secondary selection and move for editable annotations.
- Opaque shape fill; brush-style mosaic / blur that cannot be re-edited after drawing.
- Annotation color, line width, text size, and fill state are remembered; each capture starts in the select tool.

### Pin Images

- Default shortcut `F3` pins clipboard images; capture-to-pin preserves original size and screen position.
- Pin windows support wheel zoom / opacity, double-click close, and `0` to reset transforms.
- Right-click context menu: zoom, opacity, reset, toggle shadow / border, close.
- LiteSnap panel can hide / show all pinned windows at once.

### Settings

- Editable LiteSnap settings: capture / pin shortcuts, save directory and format, post-capture behavior, annotation defaults.
- Shortcut recorder, directory picker, and color picker in the settings panel.
- Global shortcuts re-register immediately on save; conflicts roll back to the previous working shortcuts with status feedback.
- One-click restore for default shortcuts (`F1` / `F3`).

## Reliability

- Fixed native addon crash loops, black captures, overlay UI leaking into saved images, and disappearing selection on repeated F1.
- Fixed accidental full-screen reselection on outside clicks and rectangular mosaic behavior.
- Build script now surfaces `EBUSY` when the native addon is locked by a running Electron instance.
