# LiteLauncher v1.0.27 发布日志

发布日期：2026-06-26

## 本版重点

本版新增 **LiteSnap 截图与贴图** 插件，提供接近 Snipaste 的首版体验，并集成 Windows 原生 GDI 截屏加速。

### LiteSnap 截图

- 默认快捷键 `F1` 进入全屏截图，支持框选、拖拽调整选区、双击复制、保存到磁盘。
- Windows 原生 GDI 截屏插件，提升 F1 唤起与抓屏速度；不可用时自动回退 Electron 截屏。
- 悬停窗口自动识别并预览，点击可快速选中窗口区域。
- 放大镜与取色器，便于精确选区和拾取颜色。

### 标注工具

- 图标化工具栏：矩形、椭圆、直线、箭头、画笔、荧光笔、文字、序号、马赛克、模糊。
- 支持撤销 / 重做 / 删除，以及标注对象的二次选中与移动。
- 形状支持实色填充；马赛克 / 模糊为画笔式涂抹，绘制后不可再编辑。
- 标注颜色、线宽、文字大小、填充状态会记住上次样式；每次截图默认从「选择」工具开始。

### 贴图

- 默认快捷键 `F3` 将剪贴板图片贴到屏幕；截图后也可直接贴图，保持原位置与原尺寸。
- 贴图窗口支持滚轮缩放 / 透明度、双击关闭、`0` 键重置。
- 右键菜单：放大 / 缩小、透明度、重置、切换阴影 / 边框、关闭。
- LiteSnap 面板支持一键隐藏 / 显示全部贴图。

### 设置

- LiteSnap 设置页可编辑：截图 / 贴图快捷键、保存目录与格式、截图后行为、标注默认值。
- 快捷键支持「录制」按钮；保存目录支持目录选择器；标注颜色支持取色器。
- 保存后立即重新注册全局快捷键；冲突时回滚到旧可用快捷键并显示注册状态。
- 提供「恢复默认快捷键（F1 / F3）」按钮。

## 稳定性与修复

- 修复原生插件加载崩溃、黑屏截图、保存图含 overlay UI、二次 F1 选区消失等问题。
- 修复误点选区外导致全屏重选、马赛克误用矩形选区等交互问题。
- 构建脚本增加 `EBUSY` 提示，避免 dev 运行时 native 文件被锁导致编译失败。
