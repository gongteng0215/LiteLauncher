# LiteLauncher v1.0.28 Release Notes

Release date: 2026-06-27

## Highlights

This release continues polishing LiteSnap, focusing on the first-`F1` grey screen, soft screenshot backgrounds, capture startup latency, and a clearer prompt after updates are downloaded.

### LiteSnap Capture Speed

- The Windows native GDI capture addon now has a combined frame path that produces the preview and full-resolution source image from one screen capture.
- Screenshot frame cache warming now starts as soon as the main process boots, then refreshes periodically while idle.
- Capture, overlay preparation, and settings loading run in parallel to reduce the delay between pressing `F1` and interacting with the overlay.
- The no-session path skips unnecessary cancel/hide work, reducing first-capture overhead.

### LiteSnap Visual Clarity

- Fixed the first `F1` capture showing a grey overlay before the screenshot appeared.
- The renderer now decodes the screenshot background before telling the main process to reveal the overlay.
- Removed the full-screen dark dimmer before a selection is drawn; the screenshot stays clear until the user selects a region.
- Restored 1:1 preview sizing for the display viewport and increased JPEG quality to avoid soft backgrounds on wide displays.

### Auto Update

- A native prompt is shown when an update has finished downloading.
- Users can choose "Install and restart now" or "Later"; each downloaded version is prompted once.
- The prompt is attached to the main window when available so it is less likely to appear behind other windows.
