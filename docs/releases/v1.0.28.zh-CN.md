# LiteLauncher v1.0.28 发布日志

发布日期：2026-06-27

## 本版重点

本版继续打磨 LiteSnap 截图体验，重点解决首次按 `F1` 时灰屏、背景发糊、截图唤起慢，以及更新下载完成后缺少明确安装提醒的问题。

### LiteSnap 截图速度

- Windows 原生 GDI 截屏新增合并帧路径，一次截屏同时生成预览图和全分辨率源图，减少重复读屏。
- 启动主程序后立即预热截图帧缓存，并在空闲时周期刷新，首次截图更容易命中缓存。
- 截屏、overlay 准备、设置读取并行执行，减少按下 `F1` 到截图可交互之间的等待。
- 无进行中截图会话时跳过不必要的取消/隐藏流程，减少首次唤起开销。

### LiteSnap 画面清晰度

- 修复首次按 `F1` 时 overlay 先显示灰色背景、随后才出现截图的问题。
- renderer 会先解码截图背景图，再通知主进程显示 overlay，避免首次截图灰屏。
- 取消全屏暗色遮罩；未选区时保持截图原貌，只有拖出选区后才让选区外变暗。
- 预览图恢复与显示器视口 1:1 显示，并提升 JPEG 质量，避免宽屏背景被缩放后发糊。

### 自动更新

- 更新包下载完成后弹出原生提示框。
- 可选择「立即安装并重启」或「稍后」，同一版本只提示一次。
- 提示框优先挂载到主窗口，减少被系统窗口遮挡的概率。
