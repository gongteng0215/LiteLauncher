# LiteLauncher v1.0.29 Release Notes

Release date: 2026-06-27

## Highlights

This release focuses on three areas: faster and smoother LiteSnap pinned images, a richer Hardware Inspector with image export, and a much more compact Clipboard Workbench.

### LiteSnap Pinned Images

- A reusable pinned-image window is now prewarmed at startup so the first pin appears faster.
- Pinned images load from a local file (JPEG when opaque, PNG when transparent) instead of a large data URL, speeding up decoding.
- The window only becomes visible after `ready-to-show`, avoiding a white flash when pinning.
- Wheel zoom updates are coalesced per animation frame, and zoom/opacity changes are applied separately to cut redundant repaints.
- Rounded corners are disabled on Windows to reduce compositing overhead while dragging.
- Double-clicking a pinned image now copies it to the clipboard (instead of closing); use Esc or the right-click menu to close.

### Hardware Inspector

- New "export image" feature renders an infographic-style report and saves it as a PNG.
- Two variants: a compact overview image and a full long image with detailed sections.
- The full image includes overview, motherboard/BIOS, CPU, GPU, memory, storage interfaces, SATA usage, disk SMART/health, firmware, partitions/volumes, temperatures, and connection tips.
- Disk health risks are surfaced as a dedicated alert block, and recommendations adapt to the detected hardware.

### Clipboard Workbench

- The layout was made significantly more compact so many more records are visible at once.
- Records are now a single-row list (icon, title, time) with the detail pane on the far right.
- Each row has a direct "copy" button that restores the entry to the system clipboard.
- Long unbroken text is truncated with an ellipsis instead of overflowing the row.

### Screenshot Capture

- Double-clicking inside the selection now copies the screenshot in any annotation tool, not just the select tool.
