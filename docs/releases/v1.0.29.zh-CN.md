# LiteLauncher v1.0.29 发布日志

发布日期：2026-06-27

## 本版重点

本版聚焦三块：更快更顺的 LiteSnap 贴图、内容更丰富且支持导出图片的硬件检测，以及更紧凑的剪贴板工作台。

### LiteSnap 贴图

- 启动时预热一个可复用的贴图窗口，首次贴图更快出现。
- 贴图改为从本地文件加载（不透明用 JPEG、含透明用 PNG），不再用超大 data URL，解码更快。
- 窗口在 `ready-to-show` 后才显示，避免贴图瞬间白屏闪烁。
- 滚轮缩放按动画帧合并更新，缩放与透明度分开应用，减少无效重绘。
- Windows 上关闭圆角，降低拖动时的合成开销。
- 双击贴图改为**复制图片到剪贴板**（不再关闭）；关闭请用 Esc 或右键菜单。

### 硬件检测

- 新增「导出图片」，把硬件报告渲染成信息图风格并保存为 PNG。
- 提供两种：精简概览图与完整长图。
- 完整长图包含概览、主板/BIOS、CPU、显卡、内存、存储接口、SATA 占用、磁盘 SMART/健康、固件、分区与卷、温度传感器以及接法建议。
- 磁盘健康风险单独以预警块呈现，建议会根据识别到的硬件自动调整。

### 剪贴板工作台

- 整体布局大幅收紧，一屏可见的记录数明显增多。
- 记录改为一条一条的单行列表（图标、标题、时间），详情面板固定在最右侧。
- 每行新增「复制」按钮，可直接把该条恢复到系统剪贴板。
- 过长且不可断行的文本用省略号截断，不再溢出盖住按钮。

### 截图

- 选区内双击复制现在在任意标注工具下都生效，不再仅限框选工具。
