# LiteLauncher v1.0.30 Release Notes

Release date: 2026-06-28

## Highlights

This release is a broad performance pass across startup, search, home interactions, and the data layer, aiming for faster cold/warm starts, smoother search and panel interactions, and more stable concurrent reads/writes.

### Startup and Data Layer

- Startup now loads the existing index from the database first so the main window is usable sooner, while the filesystem index refreshes in the background, cutting redundant startup scans and writes.
- Databases now enable WAL, `busy_timeout`, and `synchronous = NORMAL` to improve multi-connection read/write stability and reduce short lock waits.

### Search

- The search worker now keeps `catalog` / `usage` state resident; search requests only carry the query and options instead of cloning the full catalog each time, making typing feel more responsive.
- Worker state is synced only after catalog, usage frequency, or scan config changes, with timeout and fallback logic preserved.

### Home and Icons

- Icon resolution gained a concurrency cap plus an in-process LRU cache, significantly reducing repeated icon-resolution CPU/IO spikes when reopening the home view or paging.
- The empty-query home view is now a single `getHomeSections` request, deduplicating recent/pinned/plugin items before resolving icons once.
- Keyboard arrow and mouse-hover selection now toggle only the two affected rows instead of rerendering the whole list.

### Panel Interactions

- Clipboard Workbench selection and detail switching now refresh in place; structural changes (refresh/add/delete) still do a full rebuild.
- CodeAgent Switch provider/profile switching now updates only the list and detail panes, while read/save/apply still rebuild the full panel.
