# LiteLauncher v1.0.30 发布日志

发布日期：2026-06-28

## 本版重点

本版是一轮整体性能优化，覆盖启动链路、搜索、首页交互与数据层，目标是更快的冷/热启动、更顺滑的搜索与面板交互，以及更稳的多连接读写。

### 启动与数据层

- 启动优先从数据库加载已有索引让主窗口更快可用，文件系统索引改为后台刷新，减少启动期重复扫描与写库。
- 数据库统一启用 WAL、`busy_timeout` 与 `synchronous = NORMAL`，提升多连接读写稳定性、降低短时锁等待。

### 搜索

- 搜索 worker 改为常驻 `catalog` / `usage` 状态，搜索请求只传查询和参数，不再每次克隆完整目录，输入搜索更跟手。
- catalog、使用频率或扫描配置变化后才同步 worker，保留超时与回退逻辑。

### 首页与图标

- 图标解析增加并发上限与进程内 LRU 缓存，重复打开首页、翻页时显著减少图标重复解析的 CPU/IO 峰值。
- 首页空查询合并为单次 `getHomeSections` 请求，并对最近/置顶/插件去重后统一解析图标。
- 键盘方向键与鼠标悬停选择改为只切换前后两项的高亮，不再整列表重绘。

### 面板交互

- 剪贴板工作台选择记录、切换详情改为局部刷新，结构性变化（刷新/新增/删除）仍走完整重建。
- CodeAgent Switch 切换 Provider / 配置组改为只更新列表与详情区，读取配置、保存、应用等仍整面板重建。

## 已验证

- `pnpm run typecheck`
- `pnpm run build`
- `pnpm run test:regression`

## 发布前检查

- 验证冷启动与二次启动主窗口出现更快，索引在后台刷新且「重建索引」仍可用。
- 验证输入搜索跟手，方向键与鼠标悬停切换流畅。
- 验证剪贴板工作台切换记录、CodeAgent Switch 切换配置组不再整面板闪烁。
- 确认本版标签、安装包文件名和自动更新元数据中的版本号都对齐 `v1.0.30`。

## 说明

- 本次版本建议从 `v1.0.29` 升级到 `v1.0.30`。
- 本版以性能与稳定性为主，无功能性破坏改动。
