# LiteLauncher v1.0.31 Release Notes

Release date: 2026-06-29

## Highlights

Fixes a grey-screen regression introduced in v1.0.30: pressing F1 could briefly show a grey overlay before the screenshot appeared.

### Fixes

- Removed the screenshot overlay renderer frame-rate throttling so screenshot decoding is no longer slowed down.
- The overlay now waits for the renderer to decode the screenshot and mark it ready before becoming visible, retrying once if needed, so the transparent window can no longer expose the window background color (grey screen).

## Verification

- `pnpm run typecheck`
- `pnpm run build`
- `pnpm run test:regression`
- `node dist/test/litesnap-plugin-source.test.js`

## Pre-release Checklist

- On Windows, verify the first F1 after startup and a repeat F1 after cancelling no longer grey-screen, and the screenshot background is immediately clear.

## Notes

- This release advances the app from `v1.0.30` to `v1.0.31`.
- This is a fix-only patch with no breaking functional changes.
