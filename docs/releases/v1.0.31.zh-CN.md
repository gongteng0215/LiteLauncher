# LiteLauncher v1.0.31 发布日志

发布日期：2026-06-29

## 本版重点

修复 v1.0.30 引入的截图灰屏回归：按 F1 截图时 overlay 可能先显示灰屏，随后才出现截图。

### 修复

- 移除截图 overlay 渲染帧率节流，截图背景解码不再被拖慢。
- overlay 改为等渲染层把截图解码并标记就绪后才显示，必要时重试一次，彻底避免在透明窗口上提前显示窗口底色（灰屏）。

## 已验证

- `pnpm run typecheck`
- `pnpm run build`
- `pnpm run test:regression`
- `node dist/test/litesnap-plugin-source.test.js`

## 发布前检查

- 在 Windows 上验证启动后首次按 F1、以及取消后再次按 F1 都不灰屏，截图背景立即清晰。

## 说明

- 本次版本建议从 `v1.0.30` 升级到 `v1.0.31`。
- 本版为修复补丁，无功能性破坏改动。

完整变更对比：https://github.com/gongteng0215/LiteLauncher/compare/v1.0.30...v1.0.31
