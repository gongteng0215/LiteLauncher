# LiteLauncher v1.0.32 Release Notes

Release date: 2026-06-29

## Highlights

Fixes two features that the v1.0.30 performance pass accidentally broke: F3 pinning stopped working after the first use, and annotated screenshots became blurry when copied or saved.

### Fixes

- Fixed F3 pinning the clipboard image doing nothing after the first use. Reusing the prewarmed pin window no longer depends on `ready-to-show` (which only fires once); the window is shown once its content has loaded, with a safety timer so it always appears.
- Fixed annotated screenshots (arrow, rectangle, pen, text, etc.) looking blurry when copied or saved. Annotations are now always composited onto the full-resolution source image instead of the low-resolution preview.

## Verification

## Pre-release Checklist

- Press F3 several times in a row and confirm the pin window appears every time.
- Add annotations (arrow/rectangle/text) to a screenshot and confirm the copied and saved images are sharp.

## Notes

- This release advances the app from `v1.0.31` to `v1.0.32`.
- This is a fix-only patch that restores functionality regressed by optimization; no new functional changes.
