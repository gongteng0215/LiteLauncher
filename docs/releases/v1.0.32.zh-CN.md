# LiteLauncher v1.0.32 发布日志

发布日期：2026-06-29

## 本版重点

修复 v1.0.30 性能优化误伤的两个功能问题：F3 贴图第二次起失效、截图加标注后复制/保存发糊。

### 修复

- 修复 F3 贴图剪贴板图片在第一次之后无反应：复用预热贴图窗口时不再依赖只会触发一次的 `ready-to-show`，内容加载完成即显示，并加兜底定时器，保证窗口一定出现。
- 修复截图加标注（箭头、矩形、画笔、文字等）后复制/保存发糊：标注现在始终合成到全分辨率源图上，不再误用低分辨率预览图。

## 已验证

- `pnpm run typecheck`
- `pnpm run build`
- `pnpm run test:regression`
- `node dist/test/litesnap-plugin-source.test.js`
- `node dist/test/litesnap-pin-preload-source.test.js`

## 发布前检查

- 连续多次按 F3 贴图，每次都能正常弹出贴图窗口。
- 截图后加箭头/矩形/文字等标注，复制和保存出来的图清晰不发糊。

## 说明

- 本次版本建议从 `v1.0.31` 升级到 `v1.0.32`。
- 本版为修复补丁，仅恢复被优化误伤的功能行为，无新增功能改动。

完整变更对比：https://github.com/gongteng0215/LiteLauncher/compare/v1.0.31...v1.0.32
