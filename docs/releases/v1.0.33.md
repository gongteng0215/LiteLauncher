# LiteLauncher v1.0.33 Release Notes

Release date: 2026-06-29

## Highlights

Sharper LiteSnap captures, a launcher window that stays visible while you screenshot it, and a fully editable Cron quick-template list.

### Improvements

- LiteSnap capture overlay now shows the full-resolution source image instead of a low-resolution preview, so the area you are selecting looks sharp.
- Taking a screenshot (F1) no longer hides the main launcher window, so you can capture the launcher UI itself.
- Cron generator "syntax cheatsheet" now lays out horizontally as a grid instead of a tall list with empty space on the right.
- Cron quick templates are now a single editable list backed by SQLite:
  - Edit the name and expression of any template, including the five built-in presets.
  - Add your own templates (type a name and expression, or pull in the current expression).
  - Delete any template.
  - One-click "restore defaults" to bring back the original five presets.

### Fixes

- The Cron generator no longer fails to open when the template store has not been initialized; it falls back to the default templates.

## Pre-release Checklist

- Press F1, confirm the capture overlay background is sharp and the launcher window stays visible.
- Open the Cron generator, edit a preset, add a custom template, delete one, and use "restore defaults".
- Reopen the Cron generator and confirm custom templates persist.
