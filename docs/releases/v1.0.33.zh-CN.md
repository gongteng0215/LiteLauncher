# LiteLauncher v1.0.33 发布日志

发布日期：2026-06-29

## 本版重点

截图取景框更清晰、截图时主窗口不再隐藏、Cron 快速模板可完全自定义编辑。

### 改进

- LiteSnap 截图取景框改用全分辨率源图，不再显示低分辨率预览，框选区域更清晰。
- 按 F1 截图时不再隐藏主启动器窗口，可以直接截取启动器界面本身。
- Cron 生成器底部「语法速览」由竖排长列表改为横向网格，右侧不再留空。
- Cron 快速模板改为单一可编辑列表，并持久化到 SQLite：
  - 任意模板（含 5 个内置预设）都可以修改名称和表达式。
  - 可新增自己的模板（填名称和表达式，或一键带入当前表达式）。
  - 可删除任意模板。
  - 一键「恢复默认」还原初始 5 个预设。

### 修复

- 修复模板存储未初始化时 Cron 生成器打开失败的问题，会回退到默认模板。

## 已验证

- `pnpm run typecheck`
- `pnpm run build`
- `pnpm run test:regression`
- `node dist/test/webtools-cron-store.test.js`
- `node dist/test/webtools-cron-plugin.test.js`

## 发布前检查

- 按 F1，确认取景框背景清晰，且主窗口保持可见。
- 打开 Cron 生成器：编辑一个预设、新增一个自定义模板、删除一个、再点「恢复默认」。
- 重新打开 Cron 生成器，确认自定义模板仍然保留。
