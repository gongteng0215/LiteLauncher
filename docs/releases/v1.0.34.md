# LiteLauncher v1.0.34 Release Notes

Release date: 2026-06-29

## Highlights

QR code text logos now render and wrap correctly, and the timestamp tool reliably handles seconds vs. milliseconds.

### Fixes

- QR code generator: text logos are now positioned and scaled inside the QR `viewBox`, so the text actually shows up on the generated code.
- QR code generator: long logo text wraps onto multiple centered lines with adaptive font sizing instead of overflowing or being truncated to a few characters.
- Timestamp tool: a value is auto-detected as seconds or milliseconds by its digit count, so a 10-digit seconds timestamp is no longer misread as milliseconds (which previously produced a 1970 date).
- Timestamp tool: switching the unit between seconds and milliseconds now re-expresses the value on the left, so the field visibly updates.
- Timestamp tool: dates and conversions now support millisecond precision, so real millisecond timestamps round-trip without being flattened to a trailing `000`.

## Verification

- `pnpm run typecheck`
- `pnpm run build`
- `node dist/test/webtools-timestamp-plugin.test.js`
- `node dist/test/webtools-qrcode-plugin.test.js`
- `node dist/test/plugin-panel-impls-regression.test.js`

## Pre-release Checklist

- Generate a QR code with a text logo, including a long string, and confirm the text shows up and wraps inside the logo box.
- Open the timestamp tool, paste a 10-digit seconds value, and confirm it resolves to the correct current-era date.
- Switch the unit to milliseconds and confirm the left value updates accordingly.
- Convert a millisecond timestamp such as `1782739960434` to a date and back, and confirm the milliseconds survive.
