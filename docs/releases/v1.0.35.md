# LiteLauncher v1.0.35 Release Notes

Release date: 2026-07-01

## Highlights

LiteSnap gains Windows OCR, dual-engine Baidu translation, and fixes for post-capture freezes, grey overlay flashes, and stale selection UI.

### Added

- LiteSnap: OCR selected screenshot regions via Windows OCR, with editable results in the plugin panel.
- LiteSnap: Screenshot translation (English to Chinese) plus a manual translate test area in settings.
- LiteSnap: Baidu translation supports both the standard VIP API and the LLM text-translate API, selectable in settings.
- LiteSnap: Store Baidu AppID, secret, and API Key locally in SQLite.

### Fixes and improvements

- LiteSnap: Fix grey full-screen overlay, misplaced toolbar, and stale selection after OCR/translate before the next capture.
- LiteSnap: Reduce F1 freezes by pausing idle frame-cache work while the launcher is focused.
- LiteSnap: More reliable OCR via sequential engines, small-crop upscaling, and retries.
- LiteSnap: Window-hint dashed preview only appears after pointer movement and no longer covers the whole screen by default.
- LiteSnap: Re-register global shortcuts only when shortcut values change, so saving translation settings no longer hangs.

## Verification

- `pnpm run build`
- `node dist/test/baidu-translate.test.js`
- `node dist/test/litesnap-plugin-source.test.js`
- `node dist/test/litesnap-ocr-quality.test.js`
- `node dist/test/litesnap-ocr-text.test.js`

## Pre-release checklist

- Press F1, select a region, run OCR, and confirm editable text appears in the panel.
- Test screenshot translation and settings-page manual translate with both Baidu engines.
- After OCR, press F1 again and confirm no grey screen or stray toolbar.
- Fully quit the app before upgrading so the native OCR addon can load cleanly.

## Notes

- Upgrade from `v1.0.34` to `v1.0.35` is recommended.
- LLM translation requires enabling the product on Baidu Fanyi Open Platform and creating an API Key.
- English OCR requires the Windows English OCR language pack.
