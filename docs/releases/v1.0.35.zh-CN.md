# LiteLauncher v1.0.35 发布日志

发布日期：2026-07-01

## 本版重点

LiteSnap 截图贴图补齐 Windows OCR、百度双引擎翻译，并修复截图后卡顿、灰屏与选区残留等问题。

### 新增

- LiteSnap：截图选区文字识别（Windows OCR），结果可在面板中编辑与复制。
- LiteSnap：截图翻译（英译中），支持在设置中手动输入原文试译。
- LiteSnap：百度翻译支持「通用文本翻译」与「大模型文本翻译」两种引擎，可在设置中选择。
- LiteSnap：设置页可本地保存百度 AppID、密钥与 API Key（仅存本机 SQLite）。

### 修复与改进

- LiteSnap：修复 OCR/翻译后再次按 F1 时灰屏、工具栏错位、旧选区残留等问题。
- LiteSnap：修复 F1 截图时主线程被后台帧缓存抢占导致的未响应。
- LiteSnap：OCR 改为串行识别并支持小图放大与重试，识别稳定性更好。
- LiteSnap：窗口虚线预览仅在移动鼠标后出现，且不再铺满全屏误导用户。
- LiteSnap：保存设置时仅在快捷键变更时重新注册，避免仅改翻译配置时卡顿。

## 发布前检查

- 按 F1 截图 → 框选 → 文字识别，确认能出字且面板可编辑。
- 截图翻译或设置页手动翻译，分别试「通用」与「大模型」引擎。
- OCR 后再次 F1 截图，确认无灰屏、无左上角误显工具栏。
- 完全退出后重装/覆盖，确认 native OCR 模块可用。

## 说明

- 本次版本建议从 `v1.0.34` 升级到 `v1.0.35`。
- 大模型翻译需在百度翻译开放平台单独开通，并在「API Key 管理」创建 Key。
- 英文 OCR 需在 Windows 语言设置中为英语安装「光学字符识别」语言包。

完整变更对比：https://github.com/gongteng0215/LiteLauncher/compare/v1.0.34...v1.0.35
