# LiteLauncher v1.0.36 Release Notes

Release date: 2026-07-02

## Highlights

Main-process and renderer performance/robustness improvements, LiteSnap OCR capability probing with guided install, and CodeAgent Switch panel UX refinements.

### Added

- LiteSnap: OCR capability probe with cache; settings page shows module/language-pack status and install guidance.
- LiteSnap: delayed silent overlay prewarm after the launcher window is ready, reducing first F1 cold-start latency.

### Fixes & Improvements

- Main process: timeout protection for icon-association PowerShell, UAC elevation, and dynamic command resolution to avoid hung IPC.
- Main process: dynamic command resolution (`where`/PowerShell) moved to async `spawn` so search no longer blocks the main thread.
- Main process: catalog writes reuse prepared statements for faster large saves.
- Renderer: avoid full re-renders after LiteSnap/general settings saves; debounce JSON panel stats parsing.
- Renderer: crypto panel outside-click listener and hardware inspector expanded-disk state cleaned up on panel switch.

## Verified

- `pnpm run build`
- `pnpm run test:regression`
- Targeted `pnpm run test:e2e:smoke` flows (launcher, LiteSnap, settings, layout)

## Pre-release checks

- Search a simple command name (e.g. `notepad`) and confirm instant results without jank.
- After ~5s from startup, press F1 and confirm overlay responds faster than a cold first press.
- Check OCR status on LiteSnap settings and exercise one-click install if needed.
- Save settings and confirm status text updates without a full panel flash/rebuild.
