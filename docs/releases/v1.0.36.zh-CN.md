# LiteLauncher v1.0.36 发布日志

发布日期：2026-07-02

## 本版重点

主进程与渲染层性能/健壮性优化，LiteSnap OCR 能力检测与一键安装，以及 CodeAgent Switch 面板体验改进。

### 新增

- LiteSnap：OCR 能力探测与缓存，设置页可查看模块/语言包状态并引导安装。
- LiteSnap：launcher 窗口就绪后延迟静默预热截图 overlay，降低首次 F1 冷启动延迟。

### 修复与改进

- 主进程：图标关联 PowerShell 查询、UAC 提权、动态命令解析等路径增加超时保护，避免 IPC 长时间挂起。
- 主进程：动态命令解析（where/PowerShell）改为异步 spawn，搜索时不再阻塞主线程。
- 主进程：目录写库复用 prepared statement，大目录保存更快。
- 渲染层：LiteSnap/通用设置保存后避免不必要的整页重渲染；JSON 面板统计解析加防抖。
- 渲染层：加密面板 outside-click 监听器、硬件检测面板展开状态在切换面板时正确清理。

## 已验证

- `pnpm run build`
- `pnpm run test:regression`（除既有 CodeAgent e2e 选择器外均已通过）
- `pnpm run test:e2e:smoke`（launcher / LiteSnap / settings / layout 相关用例）

## 发布前检查

- 搜索简单命令名（如 `notepad`）确认结果即时返回、无卡顿。
- 首次启动约 5 秒后按 F1 截图，确认 overlay 响应明显快于冷启动。
- LiteSnap 设置页查看 OCR 状态，必要时走一键安装流程。
- 设置保存后确认状态文字更新且面板不闪烁重绘。
