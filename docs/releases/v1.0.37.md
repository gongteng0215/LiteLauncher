# LiteLauncher v1.0.37 Release Notes

Release date: 2026-07-03

## Highlights

Fixes LiteSnap OCR false negatives on Windows 11, packaged native-module path resolution, and adds a hardware-inspector compact-report preview on the right.

### Fixes

- LiteSnap: on Win11, `Get-WindowsCapability -Online -Name` can return empty even when OCR language packs are installed; enumerate `Language.OCR*` instead and fall back to local capability state.
- LiteSnap: packaged installs now resolve `litesnap-capture.node` via `app.asar.unpacked` and other fallbacks so OCR no longer reports a missing native file.
- LiteSnap: when system OCR is installed but the native module is missing, the probe page explains that clearly instead of suggesting another language-pack install.

### Added

- Hardware inspector: live compact export image preview on the right with refresh and quick export actions.

### Auto-update

- **NSIS installer** users on `v1.0.36` and earlier can check, download, and install this release automatically.
- Release assets include `latest.yml`, `LiteLauncher-Setup-1.0.37.exe`, and `.blockmap` aligned with `electron-updater` metadata.
- Portable / ZIP builds do not support auto-update; download manually.

## Verified

- `pnpm run build`
- LiteSnap OCR / native-path regression tests
- Manual Win11 installer OCR probe pass

## Pre-release checks

- From a `v1.0.36` NSIS install, open Settings → Check for updates and confirm `v1.0.37` is offered and downloads.
- LiteSnap OCR probe on Win11 with language packs installed should report components installed and module loaded.
- Hardware inspector should show the compact preview on the right.

## Notes

- Upgrade from `v1.0.36` to `v1.0.37` is recommended (installer users can wait for auto-update or check manually).
