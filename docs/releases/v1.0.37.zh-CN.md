# LiteLauncher v1.0.37 发布日志

发布日期：2026-07-03

## 本版重点

修复 Windows 11 上 LiteSnap OCR 误报未安装、打包版 native 模块路径解析，以及硬件检测面板右侧精简图预览。

### 修复

- LiteSnap：Win11 已安装 OCR 语言包时，`Get-WindowsCapability -Online -Name` 可能返回空；改为按 `Language.OCR*` 枚举，并回退本地 capability 状态，与系统管理员 PowerShell 检测结果一致。
- LiteSnap：打包安装版增加 `app.asar.unpacked` 等候选路径解析 `litesnap-capture.node`，避免 OCR 模块误报「native 文件缺失」。
- LiteSnap：系统 OCR 已装但 native 未加载时，检测页给出明确提示，避免重复一键安装语言包。

### 新增

- 硬件检测：右侧实时预览「导出精简图」，支持刷新预览与快捷导出。

### 自动更新

- **NSIS 安装版**（`LiteLauncher-Setup-x.x.x.exe`）可从 `v1.0.36` 及更早版本自动检查、下载并安装本版。
- 发布资产包含 `latest.yml`、`LiteLauncher-Setup-1.0.37.exe` 与 `.blockmap`，与 `electron-updater` 元数据一致。
- Portable / ZIP 绿色版不支持自动更新，请手动下载新版本。

## 已验证

- `pnpm run build`
- LiteSnap OCR / native 路径相关回归测试
- 本机 Win11 实机安装包 OCR 检测通过

## 发布前检查

- 在 `v1.0.36` NSIS 安装版中打开设置 → 检查更新，应能发现 `v1.0.37` 并下载。
- LiteSnap 设置页「检测 OCR」在 Win11 已装语言包时应显示组件已安装、模块已加载。
- 硬件检测面板右侧应显示精简图预览。

## 说明

- 建议从 `v1.0.36` 升级到 `v1.0.37`（安装版可等待自动更新或手动检查更新）。
