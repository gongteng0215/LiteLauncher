# LiteLauncher v1.0.38 Release Notes

Release date: 2026-07-03

## Highlights

Fixes OCR native module discovery for **NSIS installed** builds; existing installer users can upgrade via auto-update.

### Fixes

- LiteSnap: installed builds now prefer `resources/app.asar.unpacked/dist/native/litesnap-capture.node` and try multiple candidate paths before reporting a missing native module.
- LiteSnap: OCR probe shows the current app version and checked native paths for easier diagnosis.
- CI: Windows packaging now requires the native addon build and verifies `litesnap-capture.node` is present before release.

### Auto-update

- **Users on v1.0.36 / v1.0.37 (NSIS installer)**: auto-check runs ~12s after startup, or use Settings → Check for updates, then restart after v1.0.38 downloads.
- Portable / ZIP builds do not auto-update; download the new ZIP manually.

## Notes

- If auto-update does not trigger, check manually from Settings.
- After upgrading, LiteSnap OCR probe should show `v1.0.38` and a loaded native module.
