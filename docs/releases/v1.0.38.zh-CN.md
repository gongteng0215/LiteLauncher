# LiteLauncher v1.0.38 发布日志

发布日期：2026-07-03

## 本版重点

修复 **NSIS 安装版** 找不到 OCR native 模块的问题，已安装用户可通过自动更新升级。

### 修复

- LiteSnap：安装版优先从 `resources/app.asar.unpacked/dist/native/` 加载 `litesnap-capture.node`，并遍历多个候选路径尝试 `require`，避免误报 native 缺失。
- LiteSnap：OCR 检测页显示当前版本号与已检查路径，便于排查。
- CI：Windows 打包强制编译 native 模块，发布前校验安装包内包含 `litesnap-capture.node`。

### 自动更新

- **已安装 v1.0.36 / v1.0.37 的用户**：启动后约 12 秒自动检查更新，或在设置页点「检查更新」，下载 **v1.0.38** 后重启即可。
- Portable / ZIP 绿色版不支持自动更新，请手动下载新版本 ZIP。

## 说明

- 若自动更新未触发，请设置页手动「检查更新」。
- 更新完成后在 LiteSnap 设置页「检测 OCR」，应显示 `当前版本 v1.0.38` 且 native 已加载。

完整变更对比：https://github.com/gongteng0215/LiteLauncher/compare/v1.0.37...v1.0.38
