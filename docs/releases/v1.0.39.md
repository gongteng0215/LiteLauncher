# LiteLauncher v1.0.39 Release Notes

Release date: 2026-07-09

## Highlights

Fixes blurry LiteSnap screenshot preview on HiDPI displays and reduces noisy native-addon load warnings in development.

### Fixes

- LiteSnap: screenshot overlay preview now captures at physical pixel resolution (`bounds × scaleFactor`) so selection areas stay sharp on 125%/150%/200% Windows display scaling.
- LiteSnap: native addon path resolution prefers `dist/native` in unpackaged/dev runs and skips missing candidates before `require`, avoiding misleading `MODULE_NOT_FOUND` warnings when Electron still loads the addon successfully.

### Auto-update

- **Users on v1.0.38 (NSIS installer)**: auto-check runs ~12s after startup, or use Settings → Check for updates, then restart after v1.0.39 downloads.
- Portable / ZIP builds do not auto-update; download the new ZIP manually.

## Notes

- If auto-update does not trigger, check manually from Settings.
- After upgrading, screenshot selection text should look crisp before OCR/translate.
