# LiteLauncher v1.0.39 发布日志

发布日期：2026-07-09

## 本版重点

修复 **HiDPI 显示器** 上 LiteSnap 截图选区发糊的问题，并减少开发模式下 native 模块加载的误导性警告。

### 修复

- LiteSnap：遮罩预览按物理像素（`bounds × scaleFactor`）截图，125%/150%/200% 系统缩放下选区文字不再发糊，便于 OCR/翻译前查看。
- LiteSnap：未打包/开发运行时优先从 `dist/native` 加载 native 模块，并在 `require` 前跳过不存在的候选路径，避免先报 `MODULE_NOT_FOUND` 再成功加载的噪音日志。

### 自动更新

- **已安装 v1.0.38 的用户**：启动后约 12 秒自动检查更新，或在设置页点「检查更新」，下载 **v1.0.39** 后重启即可。
- Portable / ZIP 绿色版不支持自动更新，请手动下载新版本 ZIP。

## 说明

- 若自动更新未触发，请设置页手动「检查更新」。
- 更新后截图框选区域应清晰可读；`overlay ready wait timed out` 为超时警告，一般不影响正常截图。

完整变更对比：https://github.com/gongteng0215/LiteLauncher/compare/v1.0.38...v1.0.39
