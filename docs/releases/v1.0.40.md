# LiteLauncher v1.0.40 Release Notes

Release date: 2026-07-09

## Highlights

Adds a standalone **Text Translate** plugin (`webtools-translate`) and moves Baidu Translate settings out of LiteSnap. Settings now uses an icon-based plugin visibility picker instead of raw plugin ID text input.

### Added

- **Text Translate** plugin: paste or type text, English→Chinese by default, Baidu standard and LLM engines; configure Baidu App ID / credentials inside the plugin.
- Settings **visible plugins** picker: icon + name grid with required-plugin badges instead of manual ID entry.
- One-time migration of legacy LiteSnap Baidu credentials into Text Translate settings on first read.

### Improved

- Text Translate panel clears previous source/result text when reopened.
- Users on older default visible-plugin lists automatically receive the new translate plugin.
- Fixed garbled Chinese error strings in CodeAgent Switch.
- Encoding check script now detects common mojibake fragments.

### Auto-update

- **Users on v1.0.39 (NSIS installer)**: auto-check runs ~12s after startup, or use Settings → Check for updates, then restart after v1.0.40 downloads.
- Portable / ZIP builds do not auto-update; download the new ZIP manually.

## Notes

- LiteSnap screenshot-region translate remains; Baidu credentials now live under Text Translate settings.
- Selection-translate and offline dictionary work is documented but not included in this release.
