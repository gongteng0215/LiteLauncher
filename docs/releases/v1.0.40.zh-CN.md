# LiteLauncher v1.0.40 发布日志

发布日期：2026-07-09

## 本版重点

新增独立 **文本翻译** 插件（`webtools-translate`），并将百度翻译配置从 LiteSnap 中拆分出来；设置页插件可见性改为图标+名称点选，更易辨认。

### 新增

- **文本翻译** 插件：支持粘贴/输入文本、英译中（默认）、百度标准翻译与 LLM 翻译引擎；可在插件内配置百度 App ID / 密钥。
- 设置页 **显示插件** 改为图标网格点选（必选插件带标记），不再手填插件 ID。
- 旧版 LiteSnap 内的百度翻译凭据会在首次读取时自动迁移到文本翻译插件设置。

### 改进

- 打开文本翻译面板时清空上次输入与译文，避免残留内容。
- 已保存旧默认可见插件列表的用户会自动补上「文本翻译」插件。
- CodeAgent Switch 若干中文错误提示修复乱码。
- 编码检查脚本增加常见乱码片段检测。

### 自动更新

- **已安装 v1.0.39 的用户**：启动后约 12 秒自动检查更新，或在设置页点「检查更新」，下载 **v1.0.40** 后重启即可。
- Portable / ZIP 绿色版不支持自动更新，请手动下载新版本 ZIP。

## 说明

- LiteSnap 截图选区翻译仍保留；面板内「百度翻译」配置已移至「文本翻译」插件设置。
- 划词翻译与离线词典功能见设计文档，尚未在本版实现。
