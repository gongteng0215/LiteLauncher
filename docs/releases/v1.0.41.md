# LiteLauncher v1.0.41 Release Notes

Release date: 2026-07-10

## Highlights

Fixes F3 pin windows that kept growing while being dragged.

### Fixes

- LiteSnap pin: drag moves via `setBounds` with width/height locked from pin metadata, avoiding Windows HiDPI size drift from repeated `setPosition` on frameless windows.
- LiteSnap pin: ignore wheel zoom while dragging or when the gesture is mostly horizontal (trackpad pan).

### Auto-update

- **Users on v1.0.40 (NSIS installer)**: auto-check runs ~12s after startup, or use Settings → Check for updates, then restart after v1.0.41 downloads.
- Portable / ZIP builds do not auto-update; download the new ZIP manually.

## Notes

- After upgrading, dragging a pinned image should only move it; mouse wheel still zooms, and Ctrl+wheel still adjusts opacity.
