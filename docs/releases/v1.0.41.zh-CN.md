# LiteLauncher v1.0.41 发布日志

发布日期：2026-07-10

## 本版重点

修复 F3 贴图窗口在拖动时越拖越大的问题。

### 修复

- LiteSnap 贴图：拖动时用 `setBounds` 锁定宽高，避免 Windows HiDPI 下反复 `setPosition` 导致无边框窗口尺寸漂移放大。
- LiteSnap 贴图：拖动中或左右为主的触控板手势不再误触发滚轮缩放。

### 自动更新

- **已安装 v1.0.40 的用户**：启动后约 12 秒自动检查更新，或在设置页点「检查更新」，下载 **v1.0.41** 后重启即可。
- Portable / ZIP 绿色版不支持自动更新，请手动下载新版本 ZIP。

## 说明

- 更新后 F3 贴图左右拖动应只移动位置，不再自己变大；滚轮仍可正常缩放，Ctrl+滚轮仍可调透明度。

完整变更对比：https://github.com/gongteng0215/LiteLauncher/compare/v1.0.40...v1.0.41
