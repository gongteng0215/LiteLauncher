# LiteLauncher v1.0.42 Release Notes

Release date: 2026-07-14

## Highlights

Fixes pinned-item context menu / unpin behavior, and adds multi-monitor screenshot follow for LiteSnap.

### Fixes

- **Pinning**: icon attachment cache no longer overwrites live `pinned` state; pinned-section context menu correctly shows Unpin, and unpin removes the item from the pinned section.
- **Pinning**: context menu / toggle treat pinned-section membership as pinned even if a stale cache payload lost the flag.

### Added / Improved

- **LiteSnap multi-monitor**: before a selection starts, moving the mouse to another display switches the overlay and capture frame (Snipaste-style); starting a selection locks the current display.
- Sibling displays are prewarmed for faster switches.

### Auto-update

- **Users on v1.0.41 (NSIS installer)**: auto-check runs ~12s after startup, or use Settings → Check for updates, then restart after v1.0.42 downloads.
- Portable / ZIP builds do not auto-update; download the new ZIP manually.

## Notes

- Verify: pinned-section right-click shows Unpin; after F1, move between monitors to follow, then drag a selection to lock.
