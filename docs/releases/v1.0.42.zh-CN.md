# LiteLauncher v1.0.42 发布日志

发布日期：2026-07-14

## 本版重点

修复置顶右键状态错误，并支持多显示器截图跟随鼠标切屏。

### 修复

- **置顶**：图标缓存不再冲掉 `pinned` 状态；置顶区右键正确显示「取消置顶」，取消置顶后项会离开置顶区。
- **置顶**：右键菜单改为分区感知，避免因缓存导致「取消置顶没反应」。

### 新增 / 改进

- **LiteSnap 多屏截图**：未框选时可把鼠标移到另一块屏幕，遮罩与截图底图自动切换（类似 Snipaste）；开始框选后锁定当前屏。
- 其它显示器会预热截图缓存，切屏更顺畅。

### 自动更新

- **已安装 v1.0.41 的用户**：启动后约 12 秒自动检查更新，或在设置页点「检查更新」，下载 **v1.0.42** 后重启即可。
- Portable / ZIP 绿色版不支持自动更新，请手动下载新版本 ZIP。

## 说明

- 验证建议：置顶区右键应显示「取消置顶」；F1 后在多屏间移动鼠标，遮罩应跟随，框选后不再跳屏。
