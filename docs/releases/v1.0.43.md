# LiteLauncher v1.0.43 Release Notes

Release date: 2026-07-15

## Highlights

LiteSnap usability pack: pin click-through / close-all, screenshot history, and dedicated color capture; also fixes stuck pins and stale app catalog after install/uninstall.

### LiteSnap

- **Pins**: close all pins; per-pin click-through (`Ctrl+Shift+T`; Esc exits while click-through is on); rebake when crossing monitors with different DPI.
- **History**: copy / save / pin can write history; panel list plus `snap history` / “截图历史”; settings for enablement and max items.
- **Color**: loupe `C` records recent colors; dedicated color mode (default `F4`).
- **Panel**: settings cards auto-flow into columns by width; action buttons keep natural width.

### Fixes

- **Stuck pins**: Esc clears click-through globally; toggle shortcut clears all click-through first; close-all disables click-through before closing.
- **Catalog**: watch Start Menu (and related roots) and rebuild after install/uninstall; stale rebuild when showing the launcher.

### Auto-update

- Users on **v1.0.42** can auto-update to **v1.0.43**, or check manually in Settings.
- Portable / ZIP builds need a manual download.

## Notes

- Smoke: history after F1; F3/F4 and pin click-through; catalog refreshes after install; Esc recovers clickable pins.
