# LiteLauncher v1.0.43 发布日志

发布日期：2026-07-15

## 本版重点

LiteSnap「体验三件套」落地：贴图穿透/一键关闭、截图历史、独立取色；并修复贴图卡住与安装后目录不刷新的问题。

### LiteSnap

- **贴图**：支持关闭全部贴图；单张点击穿透（`Ctrl+Shift+T` 切换；穿透中 Esc 可退出）；跨显示器 DPI 变化时自动重采样，避免拖拽后发糊。
- **截图历史**：复制/保存/贴图后可写入历史；面板提供历史列表与 `snap history` /「截图历史」入口；可在设置中开关与条数上限。
- **取色**：放大镜按 `C` 会记入最近颜色；新增独立取色模式（默认 `F4`）。
- **面板布局**：配置项随窗口宽度自适应多列；底部操作用按钮自然宽度排布。

### 修复

- **贴图卡住**：点击穿透后无法点选/关闭时，可全局 Esc 退出穿透；切换穿透会先清掉全部穿透状态；关闭全部时同样先解除穿透。
- **应用目录**：监听开始菜单等目录变化，安装/卸载后自动刷新目录；显示启动器时也会按需做过期重建。

### 自动更新

- **已安装 v1.0.42 的用户**：启动后约 12 秒自动检查更新，或在设置页点「检查更新」，下载 **v1.0.43** 后重启即可。
- Portable / ZIP 绿色版不支持自动更新，请手动下载新版本 ZIP。

## 说明

- 验证建议：F1 截图后查看历史；F3/F4 与贴图穿透可用；安装软件后重开启动器目录应自动更新；贴图穿透后 Esc 可恢复点选。
