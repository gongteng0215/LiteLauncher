# LiteLauncher v1.0.44 Release Notes

Release date: 2026-07-16

## Highlights

Selection translate lands: press **F2** after selecting text to look up a word offline or translate a phrase nearby; single English words use a bundled ECDICT common-word dictionary (~20k entries).

### Selection translate

- **Hotkey**: default `F2` (configurable in Text Translation settings); simulates Ctrl+C capture and restores the previous clipboard by default.
- **Routing**: one English word → offline dictionary card (phonetic / Chinese / English gloss); otherwise → Baidu translate (existing credentials).
- **Popup**: frameless card near the cursor; dismiss by outside click, Esc, blur, or Close; Copy button included.
- **Translate panel**: single-word input also shows the offline dictionary card above the online result.

### Dictionary

- Bundled `ecdict.db` (~5 MB) filtered from ECDICT for exam tags / Collins·Oxford / high-frequency words.
- Escaped `\n` sequences from ECDICT are rendered as real line breaks.

### Auto-update

- Users on **v1.0.43** can auto-update to **v1.0.44**, or check manually in Settings.
- Portable / ZIP builds need a manual download.

## Notes

- Smoke: select `hello` → F2 shows dictionary; select a Chinese sentence → F2 shows translation (Baidu configured); click outside closes the popup.
