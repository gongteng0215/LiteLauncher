# LiteLauncher v1.0.44 发布日志

发布日期：2026-07-16

## 本版重点

划词翻译上线：选中文字后按 **F2**，单词走离线 ECDICT 词典（约 2 万常用词），句子/中文走现有百度翻译，结果在鼠标附近弹出。

### 划词翻译

- **快捷键**：默认 `F2`（可在「文本翻译」设置中修改）；模拟 Ctrl+C 抓取选区，默认抓取后还原剪贴板。
- **分流**：单个英文单词 → 离线词典卡片（音标 / 中英释义）；其它文本 → 百度翻译（沿用现有凭证）。
- **弹窗**：无边框卡片贴近光标；点外部 / Esc / 失焦 /「关闭」均可关掉；支持「复制」。
- **翻译面板**：输入单个英文单词时，结果上方同步显示离线词典卡片。

### 离线词典

- 内置 `ecdict.db`（约 5 MB），从 ECDICT 按考纲标签 / Collins·Oxford / 高频词筛选。
- ECDICT 中字面量 `\n` 会正确显示为换行。

### 自动更新

- **已安装 v1.0.43 的用户**：启动后自动检查更新，或在设置页点「检查更新」，下载 **v1.0.44** 后重启即可。
- Portable / ZIP 绿色版不支持自动更新，请手动下载新版本 ZIP。

## 说明

- 验证建议：选中 `hello` → F2 出词典；选中中文句子 → F2 出翻译（需已配置百度）；点弹窗外部应关闭。
