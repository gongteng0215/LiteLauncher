# LiteLauncher v1.0.45 Release Notes

Release date: 2026-07-17

## Highlights

Offline dictionary coverage expands to the full ECDICT common set with **phrase support**, and single English words no longer fall back to Baidu when missing.

### Dictionary

- Bundled `ecdict.db` grows from ~20k to **~760k** entries (words + phrases with Chinese glosses).
- English definitions are kept for common / exam-tagged words to balance size (~88 MB).
- Phrase lookup works for selections like `give up`, `look forward to`, `a piece of cake`, `New York`.

### Selection translate

- English words and short phrases try the offline dictionary first.
- A single word that is not in the dictionary shows an offline miss message and **does not** require Baidu credentials.
- Longer phrases that miss the dictionary still fall back to Baidu translate; Chinese / sentences keep using Baidu.

### Auto-update

- Users on **v1.0.44** can auto-update to **v1.0.45**, or check manually in Settings.
- Portable / ZIP builds need a manual download.

## Notes

- Smoke: F2 on `cup` / `give up` shows dictionary; F2 on an unknown single word does not ask for Baidu; a Chinese sentence still uses Baidu when configured.
- Installer / update package is larger because of the expanded offline dictionary.
