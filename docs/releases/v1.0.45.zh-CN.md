# LiteLauncher v1.0.45 发布日志

发布日期：2026-07-17

## 本版重点

离线词典扩到 ECDICT 全量常用词 + **词组**，单个英文词查不到时不再回退百度翻译。

### 离线词典

- 内置 `ecdict.db` 从约 2 万条扩到约 **76 万**条（含单词与词组中文释义）。
- 常用 / 考纲词保留英文释义，体积约 88MB。
- 支持划词查词组，如 `give up`、`look forward to`、`a piece of cake`、`New York`。

### 划词翻译

- 英文单词 / 短词组优先走离线词典。
- 单个单词未收录时提示离线未命中，**不再**要求填写百度 AppID / 密钥。
- 词组未收录时仍可回退百度翻译；中文 / 整句继续走百度。

### 自动更新

- **已安装 v1.0.44 的用户**：启动后自动检查更新，或在设置页点「检查更新」，下载 **v1.0.45** 后重启即可。
- Portable / ZIP 绿色版不支持自动更新，请手动下载新版本 ZIP。

## 说明

- 验证建议：F2 查 `cup` / `give up` 出词典；未知单词不弹百度凭证；中文句子在已配置百度时仍可翻译。
- 因离线词库扩大，安装包 / 更新包体积会明显增加。
