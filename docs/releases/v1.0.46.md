# LiteLauncher v1.0.46 Release Notes

Release date: 2026-07-17

## Highlights

Selection translate now falls back to Baidu when the offline dictionary misses, and hyphenated tech terms get better offline matching.

### Selection translate

- Offline dictionary first for English words / short phrases.
- **Miss → Baidu translate** (no more “won’t call Baidu” empty state for unknown single words).
- Hyphen compounds: try space/concat variants (`user-agent` → `user agent`); if still missing, compose segment glosses (`context-path` → context + path).

### Auto-update

- Users on **v1.0.45** can auto-update to **v1.0.46**, or check manually in Settings.
- Portable / ZIP builds need a manual download.

## Notes

- Smoke: known word → dictionary card; unknown word / Chinese sentence → Baidu (credentials required); `context-path` / `user-agent` show offline results when possible.
