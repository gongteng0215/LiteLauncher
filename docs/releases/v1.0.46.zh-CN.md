# LiteLauncher v1.0.46 发布日志

发布日期：2026-07-17

## 本版重点

离线词典查不到时回退百度翻译；连字符技术词（如 `context-path`）离线匹配更好。

### 划词翻译

- 英文单词 / 短词组仍优先走离线词典。
- **未命中 → 百度翻译**（不再对未知单词提示「不会请求百度」）。
- 连字符词：先试空格/拼接变体（`user-agent` → `user agent`）；仍没有则按分段合成释义（`context-path` → context + path）。

### 自动更新

- **已安装 v1.0.45 的用户**：启动后自动检查更新，或在设置页点「检查更新」，下载 **v1.0.46** 后重启即可。
- Portable / ZIP 绿色版不支持自动更新，请手动下载新版本 ZIP。

## 说明

- 验证建议：常见词出词典卡片；生僻词 / 中文句子走百度（需已配置凭证）；`context-path` / `user-agent` 尽量离线出结果。

完整变更对比：https://github.com/gongteng0215/LiteLauncher/compare/v1.0.45...v1.0.46
