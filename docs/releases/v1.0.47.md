# LiteLauncher v1.0.47 Release Notes

Release date: 2026-07-17

## Highlights

Standalone offline dictionary plugin, packaged dictionary path fix, and Windows app icon embedding for installers / portable builds.

### Offline dictionary plugin

- New **离线词典** plugin: search `词典`, `dict`, or `dictionary` to open.
- ~760k ECDICT entries; words and phrases; hyphen variants (`context-path`, `user-agent`).
- Copy definitions; Enter to look up; optional initial word when opened from search.

### Packaged dictionary reliability

- `ecdict.db` resolves via `app.asar.unpacked` on installed / portable Windows builds so offline lookup works outside dev.

### Windows icon

- `afterPack` hook applies `icon.ico` with rcedit when `signAndEditExecutable=false`, so Explorer shows the LiteLauncher icon instead of the default Electron atom.

### Auto-update

- Users on **v1.0.46** can auto-update to **v1.0.47**, or check manually in Settings.
- Portable / ZIP builds need a manual download.

## Notes

- Smoke: open **离线词典**, try `apple` and `context-path`; verify desktop / portable exe icon after fresh install or download.
