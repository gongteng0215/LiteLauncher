# LiteLauncher v1.0.47 发布日志

发布日期：2026-07-17

## 本版重点

新增离线词典插件、修复安装包内词典路径，并修复 Windows 安装包 / 便携版 exe 图标显示为 Electron 默认图标的问题。

### 离线词典插件

- 新增 **离线词典** 插件：搜索 `词典`、`dict`、`dictionary` 即可打开。
- 约 76 万 ECDICT 词条，支持单词与词组；连字符词自动尝试多种写法（如 `context-path`、`user-agent`）。
- 支持复制释义、Enter 快捷查询；从搜索带词打开时会自动查询。

### 安装包词典路径

- 已安装 / 便携版 Windows 构建优先从 `app.asar.unpacked` 加载 `ecdict.db`，离线查词在非开发环境也可正常使用。

### Windows 图标

- 打包后通过 `afterPack` + rcedit 写入 `icon.ico`（`signAndEditExecutable=false` 时仍生效），资源管理器中显示 LiteLauncher 图标而非 Electron 默认图标。

### 自动更新

- **已安装 v1.0.46 的用户**：启动后自动检查更新，或在设置页点「检查更新」，下载 **v1.0.47** 后重启即可。
- Portable / ZIP 绿色版不支持自动更新，请手动下载新版本。

## 说明

- 验证建议：打开 **离线词典** 试 `apple`、`context-path`；新安装或新下载后确认桌面 / 便携 exe 图标正确。
