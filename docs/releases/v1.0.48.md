# LiteLauncher v1.0.48 Release Notes

Release date: 2026-07-17

## Highlights

Offline dictionary becomes a daily driver: history & favorites, Chinese reverse lookup with multiple senses, reliable F2 outside-click dismiss, and a searchable / grouped / pinnable plugin picker.

### Offline dictionary

- Query history (30) and favorites (100), persisted locally.
- Chinese → English reverse lookup against ECDICT `translation` (e.g. `苹果` → `apple`).
- Multi-sense candidates in the dictionary panel and F2 popup.
- History filters: all / English / Chinese.
- Favorites support optional notes.
- FTS5 index is applied at build time to `dist/assets/ecdict.db` (committed `src/assets/ecdict.db` stays ~88MB without FTS for GitHub limits).

### Selection translate (F2)

- Setting: **点击空白关闭** (`dismissOnOutsideClick`).
- Backdrop uses a real HTML + preload click path so outside clicks dismiss reliably when enabled.
- Popup shows direction label (英→中 / 中→英) and alternate senses for Chinese queries.
- Copy includes word + phonetic + gloss.

### Text translate panel

- Short Chinese input can also show an offline dictionary card before Baidu translate.

### Plugin visibility settings

- Search plugins by name.
- Grouped categories (词典与翻译 / 工作台 / 开发工具 / 其他).
- Pin selected plugins (★) so they stay earlier in the visible list.
- One-click restore defaults; unused default plugins show a 「新增」 tip.

### Auto-update

- Users on **v1.0.47** can auto-update to **v1.0.48**, or check manually in Settings.
- Portable / ZIP builds need a manual download.
