# LiteLauncher v1.0.48 发布日志

发布日期：2026-07-17

## 本版重点

离线词典可日常使用：历史/收藏、中译英与多义项、F2「点击空白关闭」可靠生效，设置页插件支持搜索、分类与置顶。

### 离线词典

- 查询历史（最多 30 条）与收藏（最多 100 条），本机持久化。
- 中译英：输入「苹果」「上下文」等可反向匹配 ECDICT 中文释义。
- 多义项：词典面板与 F2 弹窗展示「其他释义」，可切换。
- 历史筛选：全部 / 英文 / 中文。
- 收藏支持备注。
- 构建时为 `dist/assets/ecdict.db` 自动打 FTS 索引；仓库内 `src/assets/ecdict.db` 仍为约 88MB（无 FTS），以符合 GitHub 100MB 限制。

### 划词翻译（F2）

- 新增设置项 **点击空白关闭**。
- 空白层改为 HTML + preload 点击关闭，开启时点空白可稳定消失。
- 弹窗显示查询方向（英→中 / 中→英），中文查询可切换备选词条。
- 复制按钮复制「词 + 音标 + 释义」。

### 文本翻译面板

- 短中文也会先尝试离线词典卡片，再走百度翻译。

### 插件可见性

- 支持按名称搜索。
- 按分类分组（词典与翻译 / 工作台 / 开发工具 / 其他）。
- 已选插件可 ★ 置顶，保存后在可见列表中靠前。
- 一键「恢复默认可见」；未启用的默认推荐插件显示「新增」提示。

### 自动更新

- **已安装 v1.0.47 的用户**：启动后自动检查更新，或在设置页点「检查更新」。
- Portable / ZIP 请手动下载新版本。

## 说明

- 验证建议：词典查 `apple` / `苹果` 看多义项；F2 开关「点击空白关闭」各测一次；设置页搜索/置顶插件；重启后历史与收藏仍在。
