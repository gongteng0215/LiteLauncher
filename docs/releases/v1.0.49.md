# LiteLauncher v1.0.49 Release Notes

Release date: 2026-07-17

## Highlights

Hotkey tweaks so selection translate no longer fights Windows Explorer rename.

### Selection translate

- Default hotkey changed from **F2** to **F4** (F2 is commonly used for rename).
- Existing installs that still have F2 saved are migrated to F4 on launch; the hotkey remains editable in Text Translate settings.

### LiteSnap

- **Removed the global color-picker shortcut**; color capture is button-only from the LiteSnap panel.
- The color shortcut setting was removed from the LiteSnap settings UI.

### Auto-update

- Users on **v1.0.48** can auto-update to **v1.0.49**, or check manually in Settings.
- Portable / ZIP builds need a manual download.

## Notes

- Defaults: `F1` screenshot / `F3` pin / `F4` selection translate.
- Smoke: select text → F4 shows dictionary/translate; F2 no longer triggers selection translate; LiteSnap color pick works only via the button.
