# LiteLauncher v1.0.49 发布日志

发布日期：2026-07-17

## 本版重点

调整划词与 LiteSnap 快捷键，避免与系统「重命名」冲突。

### 划词翻译

- 默认快捷键由 **F2** 改为 **F4**（F2 常被资源管理器用于重命名）。
- 已保存为 F2 的用户启动后会自动迁移到 F4；仍可在「文本翻译」设置中自定义。

### LiteSnap

- **取消取色全局快捷键**；取色仅通过 LiteSnap 面板「取色」按钮触发。
- 设置页不再显示「取色快捷键」配置项。

### 自动更新

- **已安装 v1.0.48 的用户**：启动后自动检查更新，或在设置页点「检查更新」。
- Portable / ZIP 请手动下载新版本。

## 说明

- 当前默认：`F1` 截图 / `F3` 贴图 / `F4` 划词翻译。
- 验证建议：选中文字按 F4 出词典/翻译；确认 F2 不再触发划词；LiteSnap 取色只能点按钮。

完整变更对比：https://github.com/gongteng0215/LiteLauncher/compare/v1.0.48...v1.0.49
