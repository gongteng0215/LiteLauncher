# LiteLauncher v1.0.50 Release Notes

Release date: 2026-07-20

## Highlights

Fixes the whole-app lag after v1.0.48 / v1.0.49 where the launcher window took long to appear and every action felt delayed. Also hardens selection-popup multi-display dismiss behavior.

### Performance

- **Clipboard Workbench**: auto-collect now fingerprints clipboard images with a small thumbnail first; unchanged images no longer get a full PNG encode about every 700ms (the main cause of main-process lag).
- **LiteSnap**: removes periodic idle full-screen capture refresh; uses a one-shot warm-up instead.
- **Catalog scan**: defers Start Menu / filesystem catalog rebuild after startup so it does not compete with the first Alt+Space show.

### Selection translate

- Dismiss backdrop covers the virtual desktop across monitors and updates on display changes.
- Suspends launcher auto-hide while the popup is open; backdrop clicks on the launcher restore focus correctly.

### Quality

- Adds dictionary / selection E2E smoke coverage and popup bounds unit tests.
- Avoids repeatedly reopening the same dictionary database during FTS probing.

### Auto-update

- **Installed v1.0.49 users**: the app checks for updates on launch, or use Settings → Check for updates.
- Portable / ZIP users should download the new build manually.

## Verification

1. Put a screenshot on the clipboard, then press Alt+Space — the window should appear quickly and typing should stay responsive.
2. Select text and press F4 — popup and outside-click dismiss should work.
3. F1 capture still works (first press may be slightly slower without continuous idle refresh, but everyday use is no longer dragged down by background captures).
