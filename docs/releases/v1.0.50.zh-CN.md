# LiteLauncher v1.0.50 发布日志

发布日期：2026-07-20

## 本版重点

修复 v1.0.48 / v1.0.49 后主界面唤起慢、操作全面延迟的问题，并加固划词弹窗边界表现。

### 性能

- **剪贴板工作台**：自动采集时先用缩略图指纹判断剪贴板是否变化；图片未变化时不再每约 700ms 对整图做 PNG 编码（这是主进程卡顿的主要原因）。
- **LiteSnap**：取消空闲时周期性全屏截屏预热，改为一次性预热，避免后台持续抢 CPU/GPU。
- **索引扫描**：启动后延后扫描开始菜单等目录，减少与首次 Alt+Space 唤起的主线程竞争。

### 划词翻译

- 多显示器下 dismiss backdrop 覆盖虚拟桌面范围，并在显示器变化时更新边界。
- 弹窗打开期间可挂起主窗口自动隐藏；点击 backdrop 时，若落在启动器窗口内会正确回传焦点。

### 质量

- 新增词典 / 划词相关 E2E 冒烟与边界单元测试。
- 词典路径探测与 FTS 检查避免对同一文件重复打开。

### 自动更新

- **已安装 v1.0.49 的用户**：启动后自动检查更新，或在设置页点「检查更新」。
- Portable / ZIP 请手动下载新版本。

## 验证建议

1. 剪贴板里放一张截图后，按 Alt+Space：主界面应能较快出现，输入不应明显拖沓。
2. 选中文字按 F4：弹窗与空白处关闭正常。
3. F1 截图仍可用（首次可能略慢于「持续预热」版，但日常使用不再被后台截屏拖慢）。
