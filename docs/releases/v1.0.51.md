# LiteLauncher v1.0.51 Release Notes

Release date: 2026-07-20

## Highlights

Dictionary study features plus a smaller Windows installer: the full FTS index is an optional download (roadmap v1.0.52 packaging work is included here).

### Dictionary enhancements

- **Export favorites CSV**: export the vocabulary list (`word` / `phonetic` / `translation` / `note` / `savedAt`) with a UTF-8 BOM for Excel.
- **Inflection display**: show ECDICT `exchange` forms (past tense, plural, etc.); English glosses are labeled separately.
- **Optional TTS**: toggle “speak after lookup” (system `speechSynthesis`, off by default), plus a manual Speak button.

### Installer size and full index pack

- Windows builds ship a **slim dictionary** (no FTS) for a smaller installer; Chinese reverse lookup still works via LIKE fallback.
- For faster Chinese lookup, use **Download full index** in the dictionary panel (Release asset `ecdict-fts.db` under userData).
- Local `pnpm build` still patches FTS by default for development.

### Auto-update

- **Installed v1.0.50 users**: the app checks for updates on launch, or use Settings → Check for updates.
- Portable / ZIP users should download the new build manually.
