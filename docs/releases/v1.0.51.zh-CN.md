# LiteLauncher v1.0.51 发布日志

发布日期：2026-07-20

## 本版重点

词典学习能力增强，并缩小安装包体积：完整 FTS 索引改为按需下载（原路线图 v1.0.52 一并合入）。

### 词典增强

- **导出收藏 CSV**：离线词典面板可导出生词本（word / phonetic / translation / note / savedAt），UTF-8 BOM 便于 Excel 打开。
- **词形变化展示**：查询结果展示 ECDICT `exchange`（过去式、复数等）；英文释义单独标注。
- **可选 TTS 朗读**：设置「查词成功后朗读」（系统 `speechSynthesis`，默认关闭）；也可点「朗读」按钮。

### 安装体积与完整索引

- Windows 安装包改为携带**精简词典**（无 FTS，体积更小）；中译英仍可用 LIKE 降级。
- 需要更快中译英时，可在词典面板「下载完整索引」到本机用户目录（Release 资产 `ecdict-fts.db`）。
- 本地开发 `pnpm build` 仍默认打 FTS，方便调试中文反查。

### 自动更新

- **已安装 v1.0.50 的用户**：启动后自动检查更新，或在设置页点「检查更新」。
- Portable / ZIP 请手动下载新版本。

## 验证建议

1. 收藏几个词 →「导出收藏 CSV」→ 用 Excel/记事本打开确认中文正常。
2. 查询 `eat` 等词，确认「词形变化」显示。
3. 打开朗读开关，查词后应听到系统发音。
4. 精简包下中译英可用；下载完整索引后状态变为「已启用本机完整索引」。
