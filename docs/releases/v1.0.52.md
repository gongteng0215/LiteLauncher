# LiteLauncher v1.0.52 Release Notes

Release date: 2026-07-20

## Highlights

Three WebTools / Cashflow additions: JSON Schema validation, Cashflow review, and text masking with fake data generation.

### JSON Schema validator (`webtools-json-schema`)

- Search for “JSON Schema” or “Schema 校验” to open the panel.
- Paste Schema on the left and Payload on the right, then validate.
- Failures list JSON Pointer paths and messages; copy results in one click.
- Added to the default visible plugin list (Developer Tools group).

### Cashflow review V1 (`cash review`)

- `cash review` is no longer a placeholder; it opens the review panel.
- Per-turn decision timeline with income / expense / asset summaries.
- Settlement summary card with score and short advice; works alongside `cash stat` and `cash ai`.

### Text masking / fake data (`webtools-data-mask`)

- Search for “脱敏” or “假数据” to open the panel.
- Mask phone numbers, emails, and ID card numbers in one click.
- Generate sample names, emails, phones, UUIDs, and company names for testing.
- Added to the default visible plugin list.

### Auto-update

- **Installed v1.0.51 users**: the app checks for updates on launch, or use Settings → Check for updates.
- Portable / ZIP users should download the new build manually.

## Verification

1. Open the JSON Schema panel; validate `{ "id": "x" }` against a schema requiring numeric `id` and confirm path + message.
2. Search `cash review` and confirm the decision timeline and summary card.
3. Paste text with phone/email into the masking panel and confirm masking; use Generate to get multiple sample lines.
