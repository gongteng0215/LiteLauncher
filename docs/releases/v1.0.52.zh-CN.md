# LiteLauncher v1.0.52 发布日志

发布日期：2026-07-20

## 本版重点

三个 WebTools / Cashflow 小工具落地：JSON Schema 校验、现金流复盘、文本脱敏与假数据生成。

### JSON Schema 校验器（`webtools-json-schema`）

- 搜索「JSON Schema」或「Schema 校验」打开面板。
- 左侧粘贴 Schema，右侧粘贴 Payload，一键校验。
- 校验失败时列出 JSON Pointer 路径与错误信息，可一键复制结果。
- 默认加入可见插件列表（开发工具分组）。

### Cashflow 复盘 V1（`cash review`）

- `cash review` 不再占位，打开复盘面板。
- 按回合展示决策时间线（收入 / 支出 / 资产变动摘要）。
- 结算总结卡：评分与简短建议；与 `cash stat`、`cash ai` 入口并存。

### 文本脱敏 / 假数据（`webtools-data-mask`）

- 搜索「脱敏」或「假数据」打开面板。
- 一键脱敏手机号、邮箱、身份证号。
- 批量生成姓名、邮箱、手机、UUID、公司名等测试数据。
- 默认加入可见插件列表。

### 自动更新

- **已安装 v1.0.51 的用户**：启动后自动检查更新，或在设置页点「检查更新」。
- Portable / ZIP 请手动下载新版本。

## 验证建议

1. 打开 JSON Schema 面板，用简单 `{ "type": "object", "properties": { "id": { "type": "number" } }, "required": ["id"] }` 校验 `{ "id": "x" }`，应看到 path 与 message。
2. 搜索 `cash review`，确认决策时间线与总结卡可见。
3. 在脱敏面板粘贴含手机/邮箱的文本，确认脱敏后格式合理；点「生成假数据」应得到多行样本。
