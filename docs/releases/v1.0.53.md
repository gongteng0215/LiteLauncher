# LiteLauncher v1.0.53 Release Notes

Release date: 2026-07-21

## Highlights

Smaller installer with a seed dictionary by default; full dictionary is optional. Custom pins for arbitrary files/folders.

### Tiered dictionary download

- Installer ships a **seed dictionary** (~7k exam-tagged words / ~2MB). Installer size drops by ~85MB.
- Download the full pack from the Offline Dictionary panel (~160MB, full entries + FTS reverse lookup).
- Download shows a progress bar and verifies SHA256 after completion.
- Selection-translate misses on the seed pack hint that a full pack can be downloaded.

### Upgrade notes (important)

- **New installs**: seed dictionary by default; download full pack when needed.
- **Users who already downloaded the FTS/full pack** (`userData/dictionary/ecdict.db`): unchanged.
- **Users who relied only on the bundled full dictionary**: after upgrade you get the seed pack. Open Offline Dictionary → Download full dictionary to restore ~760k entries.
- Release assets must include `ecdict-fts.db` and `ecdict-fts.db.sha256`.

### Custom pins

- Pin any file or folder from Home / Settings without requiring it to be in scan directories.
- Custom pins appear with other pinned items and can be unpinned.

### Auto-update

- **Installed v1.0.52 users**: the app checks for updates on launch, or use Settings → Check for updates.
- Portable / ZIP users should download the new build manually.
