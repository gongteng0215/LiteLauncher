# LiteLauncher v1.0.53 发布日志

发布日期：2026-07-21

## 本版重点

安装包进一步瘦身：默认只带种子词库；完整词典改为按需下载。同时支持自定义置顶任意文件/文件夹。

### 词典分层按需下载

- 安装包内置**种子词库**（约 7k 词 / ~2MB，覆盖中考/四六级常用词），安装体积约减少 85MB。
- 需要完整能力时，在离线词典面板点击「下载完整词库」（约 160MB，含全量词条 + FTS 中译英加速）。
- 下载过程显示进度条；下载完成后校验 SHA256，防止半包损坏。
- 划词未命中时，若当前为种子词库，会提示可下载完整词库。

### 升级说明（重要）

- **新装用户**：默认种子词库，需要时再下载完整包。
- **已下载过完整索引的用户**（`userData/dictionary/ecdict.db` 已存在）：不受影响。
- **从未下载、一直依赖安装包内置全量词典的用户**：升级后会变为种子词库。请打开「离线词典」面板，点击「下载完整词库」恢复约 76 万词条能力。
- Release 资产需包含：`ecdict-fts.db` 与 `ecdict-fts.db.sha256`。

### 自定义置顶

- 首页 / 设置可自行选择任意文件或文件夹加入置顶，不必出现在扫描目录中。
- 自定义置顶项与普通置顶一起展示，可取消置顶。

### 自动更新

- **已安装 v1.0.52 的用户**：启动后自动检查更新，或在设置页点「检查更新」。
- Portable / ZIP 请手动下载新版本。

## 验证建议

1. 新装或升级后打开离线词典，确认状态为「种子词库」；查询 `apple` 等常用词可用。
2. 下载完整词库，确认进度条、完成后状态变为完整词库，中译英更快。
3. 在设置中添加自定义文件/文件夹置顶，确认首页可见并可打开。
4. 划词一个生僻词：种子词库下应提示可下载完整词库。
