# LiteLauncher v1.1.0 Release Notes

Release date: 2026-07-23

## Highlights

Command Center redesign, runtime appearance themes, and a new 3D tech app icon.

### Command Center UI

- New home layout: quick actions, search command zone, system entries, and plugin grid.
- Settings opens as a fixed-height overlay with left-nav groups.
- Search results render inline in the command surface.

### Appearance themes

- Settings → Appearance: switch presets (violet / azure / emerald / amber / rose) or pick a custom accent.
- Theme tokens (`--ll-*`) drive Command Center, settings, and plugin panels so the whole UI recolors together.
- Theme choice is persisted in SQLite and applied on startup.

### Branding

- Replaced the bundled Windows app / tray / installer icon with the new 3D tech pack (rocket + magnifier).

### Docs

- README refreshed with screenshots of home, search, settings, and representative plugins.

### Auto-update

- **Installed v1.0.53 users**: the app checks for updates on launch, or use Settings → Check for updates.
- Portable / ZIP users should download the new build manually.

## Verification

1. Launch with `Alt+Space` and confirm the Command Center home layout.
2. Open Settings → Appearance, switch to Azure / Emerald, confirm borders, nav highlight, and primary buttons recolor.
3. Open Password Tool / Clipboard Workbench and confirm they follow the active theme.
4. Confirm tray and window icons show the new 3D icon after restart / reinstall.
