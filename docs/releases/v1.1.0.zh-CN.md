# LiteLauncher v1.1.0 发布日志

发布日期：2026-07-23

## 本版重点

Command Center 全新首页、设置内可切换外观主题，以及新的 3D 科技版应用图标。

### Command Center 界面

- 新首页：快捷能力、搜索命令区、系统入口、插件网格。
- 设置改为固定高度覆盖层 + 左侧分组导航。
- 搜索结果在命令区内联展示。

### 外观主题

- 设置 → 外观主题：可选暗紫 / 青蓝 / 翠绿 / 琥珀 / 玫红，或自定义主色。
- 通过 `--ll-*` Token 驱动首页、设置与插件面板，整套界面一起换色。
- 主题写入 SQLite，启动时自动恢复。

### 品牌图标

- 替换 Windows 应用 / 托盘 / 安装包图标为新的 3D 科技版（火箭 + 放大镜）。

### 文档

- README 更新，补充首页、搜索、设置与代表插件截图。

### 自动更新

- **已安装 v1.0.53 的用户**：启动后自动检查更新，或在设置页点「检查更新」。
- Portable / ZIP 请手动下载新版本。

## 验证建议

1. `Alt+Space` 唤起，确认 Command Center 首页布局。
2. 打开设置 → 外观主题，切换青蓝 / 翠绿，确认边框、导航高亮、主按钮一并变色。
3. 打开密码工具 / 剪贴板工作台，确认跟随当前主题。
4. 重启或重装后，确认托盘与窗口图标为新 3D 图标。
