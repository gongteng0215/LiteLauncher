# LiteLauncher v1.1.1 Release Notes

Release date: 2026-07-23

## Highlights

Command Center home polish: cleaner hide→home restore, custom pins that refresh immediately, and a tighter recent section.

### Hide / reopen

- Reset to home synchronously before hide, waiting for a painted frame.
- Show under opacity 0 until home is ready, avoiding a flash of the previous search or plugin view.
- Disable Windows window animations that can replay a stale bitmap.

### Custom pins

- Fix “Add file / folder” not updating the home pinned section (stale home cache).
- Keep auto-hide suspended across the picker → persist → refresh path.
- Do not hide explicit custom pins behind catalog path filters.

### Home layout

- Remove the purple icon plate behind app / plugin icons.
- Cap “Recent” to at most two rows so pinned and plugins stay usable.

### Performance

- Cache home sections and search result pages to cut redundant IPC.
- Snappier search debounce and less focus / size thrash on show.

### Auto-update

- **Users already on v1.1.0**: the app checks for updates on launch, or use Settings → Check for updates.
- Portable / ZIP builds: download the new build manually.

## Suggested checks

1. Search or open a plugin, hide, then reopen — home should appear without a stale-frame flash.
2. Add a custom pinned file from home and confirm it appears immediately.
3. Confirm Recent is at most two rows and icons have no purple plate.
