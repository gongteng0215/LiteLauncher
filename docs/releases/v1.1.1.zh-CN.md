# LiteLauncher v1.1.1 发布日志

发布日期：2026-07-23

## 本版重点

Command Center 首页体验打磨：隐藏回到主页更干净、自定义置顶可即时生效，并收紧最近访问占用。

### 隐藏 / 再打开

- 隐藏前同步重置到主页，并等待绘制完成后再收起窗口。
- 再次显示时先以透明态确认主页，避免闪一下旧的搜索或插件页。
- 关闭 Windows 窗口动画，减少脏帧回放。

### 自定义置顶

- 修复「添加文件 / 文件夹」后首页置顶区不刷新的问题（主页缓存未失效）。
- 选文件对话框关闭后不再因失焦打断写入流程。
- 自定义置顶项不再被扫描路径过滤规则误隐藏。

### 首页布局

- 去掉图标外的紫色底板，直接显示应用 / 插件图标。
- 「最近访问」最多两行，避免挤压下方置顶与插件区。

### 性能

- 主页分区缓存、搜索结果页缓存，减少重复 IPC。
- 搜索输入防抖更快，唤起时减少多余聚焦与尺寸同步。

### 自动更新

- **已安装 v1.1.0 的用户**：启动后自动检查更新，或在设置页点「检查更新」。
- Portable / ZIP 请手动下载新版本。

## 验证建议

1. 搜索或打开插件后隐藏，再打开应直接进入主页且无明显闪屏。
2. 首页置顶区「添加文件」，确认立刻出现在置顶列表。
3. 确认最近访问最多两行，图标无紫色方底板。
