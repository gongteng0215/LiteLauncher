# LiteLauncher v1.1.10 发布日志

发布日期：2026-08-10

## 紧急修复：LiteSnap 长截图

- 长截图现在通过 Windows 系统级鼠标滚轮输入驱动目标应用，不再依赖部分应用会忽略的窗口消息。
- 目标窗口优先按选区中心鼠标下的实际应用锁定；当 LiteSnap 控制条遮挡选区时，才回退为排除 LiteSnap 自身的窗口查找。
- 浮动控制条使用非激活方式显示，并优先放置在选区外，避免抢走滚动窗口焦点或拦截滚轮。
- 滚动后等待界面动画稳定再取下一帧，降低动态界面被误判为拼接失败的概率。
- 原生截图模块一旦编译失败，构建会明确失败，绝不再悄悄沿用旧的 `.node` 模块。

## 验证

- 已重新编译 Windows 原生截图模块。
- 已使用外部记事本窗口验证：目标窗口定位正确，滚轮输入后正文像素发生位移。
- LiteSnap 源码回归、完整 Electron smoke 与 Windows NSIS/ZIP 打包校验均通过。
