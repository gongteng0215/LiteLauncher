# LiteLauncher v1.1.11

Released: 2026-08-10

## Hotfix: LiteSnap long capture

- Long capture now drives the target application with Windows system-level wheel input rather than window messages that some applications ignore.
- Target resolution prefers the application directly under the selected point and only falls back to an external-window search when LiteSnap's controller covers that point.
- The floating controller is shown without activation and is placed outside the selected area whenever possible, so it does not steal focus or intercept wheel input.
- Frame capture waits for real scroll animations to settle before matching the next frame.
- A native capture compile failure now fails the build instead of silently publishing a stale `.node` module.
- Added the C++/WinRT coroutine compatibility macro required by the GitHub Windows 2026 compiler, so the release environment rebuilds the native module successfully.

## Verification

- Verified scrolling against an external Notepad window: target bounds resolved correctly and the text viewport changed after injected wheel input.
- LiteSnap source checks, full Electron smoke, and Windows NSIS/ZIP package verification all passed.
