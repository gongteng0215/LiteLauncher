# LiteLauncher v1.1.12

Released: 2026-08-13

## Stable manual LiteSnap long capture

- Long capture is now fully user-scrolled. It ends only when the user chooses **Finish and save**; reaching an edge never auto-finishes, hides, or saves the session.
- Downward, upward, and reversed scrolling are supported. Returning through an already captured range and then crossing its top or bottom extends the result without replacing verified content.
- The dimmed outside area, dashed selection guide, and controller remain visible throughout capture without appearing in the saved image. `Esc` always cancels the session.
- Finishing waits for and validates the final frame, then saves at the original selection width to avoid first-frame-only output, missing bottoms, or oversized exports.

## Reliability and performance

- Windows captures the selected physical-pixel region directly, with unified handling for multiple displays, negative coordinates, and 100%–200% DPI.
- Prepared bitmap and grayscale data are reused across matching passes, with improved handling for fractional scrolling, fixed headers, repeated content, direction changes, and low-confidence matches.
- Stitch memory retains only added pixel segments and required viewport frames. Diagnostics now include sampled, accepted, and rejected frames, direction changes, physical selection size, and estimated peak memory.
- Native addons use content-hashed filenames and an atomic active manifest, so a running process locking an old module no longer blocks a new build.
- The development launcher rejects duplicate instances and serializes Electron restarts, preventing background process buildup that can break shortcuts, masks, and capture sessions.

## Verification

- Regression coverage includes bidirectional stitching, crossing a previously captured boundary after reversing, final-frame handling, mask lifecycle, finish/cancel races, DPI coordinates, native manifests, and duplicate-start prevention.
- A real Windows native scrolling-window run verified the top and bottom markers, output height, and exclusion of the dashed guide.
- An in-place `v1.1.11 → v1.1.12` NSIS upgrade passed in a disposable installation directory, with LiteSnap settings, history, diagnostics, and updater support still readable afterward.
- The release gate runs the complete source regression suite, Electron smoke suite, encoding checks, and Windows NSIS/ZIP package verification.
