# LiteLauncher v1.1.12 发布日志

发布日期：2026-08-13

## LiteSnap 手动长截图稳定版

- 长截图改为完全由用户手动滚动；只有点击“完成并保存”才结束，不会自动到底、自动消失或自动保存。
- 支持向下、向上以及中途反向滚动；回到已采集区域后再越过顶部或底部，会继续扩展图片而不是覆盖原有内容。
- 长截图期间持续显示选区外半透明遮罩、选区虚线框和控制条，这些界面不会被截入结果；`Esc` 可随时取消。
- 完成时等待并校验最后一帧，保存原始选区宽度的长图，避免只保存首帧、遗漏底部或导出尺寸异常。

## 稳定性与性能

- Windows 长截图直接采集选区物理像素，统一处理多屏、负坐标与 100%–200% DPI，不再先抓全屏后裁剪。
- 拼接器复用已准备的位图与灰度特征，改进非整步滚动、固定栏、重复内容、方向切换和低置信度拒绝。
- 拼接内存只保留新增像素段和必要视口，诊断中新增采样、接受/拒绝帧、方向切换、选区物理尺寸与峰值内存估算。
- 原生模块使用内容哈希文件名和原子活动清单，旧模块被运行中进程锁定时也不影响新版构建。
- 开发启动器会阻止重复实例，Electron 重启请求串行化，避免后台累积多个进程导致快捷键失效、遮罩不显示或截图卡死。

## 验证

- 覆盖双向拼接、反向后再越过已采集边界、终帧、遮罩、取消/完成竞态、DPI 坐标、原生清单和防重复启动回归。
- 真实 Windows 原生滚动窗口用例已验证顶部/底部标记、输出高度和虚线框排除。
- 已在可回收临时安装目录完成 `v1.1.11 → v1.1.12` NSIS 原位升级，LiteSnap 设置、历史、诊断和更新支持状态均可正常读取。
- 发布前执行完整源码回归、Electron smoke、编码检查与 Windows NSIS/ZIP 打包校验。
