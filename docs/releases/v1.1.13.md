# LiteLauncher v1.1.13

Released: 2026-08-13

## Modular renderer panels

- Added the internal `RendererPanelModuleRegistry`, `RendererPanelModule`, and explicit `RendererPanelHost` contracts. Every default visible plugin now has one registered implementation.
- Duplicate module IDs, duplicate plugin IDs, missing implementations, and an unconfigured Host fail loudly in development. Production builds show a recoverable panel message and write a sanitized renderer error.
- Split LiteSnap, CodeAgent Switch, Cashflow, Hardware Inspector, and Clipboard Workbench out of the legacy panel implementation file while preserving their existing UI and keyboard behavior.
- Grouped the remaining panel implementations by structured data, security, text, media, developer, and dictionary/translation responsibilities.

## LiteSnap service boundaries

- Extracted frame caching, OCR, image composition, capture commit/export, diagnostics, and overlay lifecycle handling into dedicated services.
- Reduced the capture session manager to session, window, and long-capture coordination without changing public IPC, persisted settings, or SQLite schemas.
- Added source contracts that prevent the compatibility facade, feature modules, renderer controllers, and LiteSnap manager from growing back beyond their agreed size budgets.

## Compatibility

- This release contains internal architecture work only. Plugin commands, user settings, database tables, shortcuts, LiteSnap behavior, and existing workflows remain compatible.
- macOS artifacts remain unsigned; LiteSnap long capture remains Windows-only.
