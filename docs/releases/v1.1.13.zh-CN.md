# LiteLauncher v1.1.13 发布日志

发布日期：2026-08-13

## 渲染面板模块化

- 新增内部 `RendererPanelModuleRegistry`、`RendererPanelModule` 与显式 `RendererPanelHost`，所有默认可见插件均有且只有一个注册实现。
- 重复模块 ID、重复插件 ID、实现缺失与 Host 未配置会在开发环境直接报错；生产环境显示可恢复提示并写入脱敏渲染错误日志。
- LiteSnap、CodeAgent Switch、Cashflow、Hardware Inspector、Clipboard Workbench 已从旧面板巨型文件拆出，界面和键盘操作保持兼容。
- 其余插件按结构化数据、安全、文本、媒体、开发者以及词典/翻译职责分组。

## LiteSnap 服务边界

- 帧缓存、OCR、图片合成、截图提交/导出、诊断和 overlay 生命周期已抽为独立服务。
- 截图会话管理器只保留会话、窗口和长截图协调；公开 IPC、用户设置和 SQLite 表结构均未改变。
- 新增结构门禁，限制兼容门面、功能模块、渲染控制器和 LiteSnap 管理器重新膨胀。

## 兼容性

- 本版只调整内部工程结构，插件命令、用户设置、数据库、快捷键、LiteSnap 行为和现有操作流程保持兼容。
- macOS 资产继续保持未签名说明；LiteSnap 长截图仍仅支持 Windows。
