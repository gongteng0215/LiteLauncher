# LiteLauncher v1.1.14

Released: 2026-08-13

## Unified application UI

- Introduced shared 4/8/12/16/24 px spacing, 8/12 px radii, 36 px controls, focus rings, disabled states, status blocks, cards, form grids, toolbars, and visible action areas.
- Unified the page hierarchy across Home, Search, Settings, plugin panels, Cashflow, selection translation, Dictionary, LiteSnap, and pinned-image windows while retaining the existing dark theme and accent direction.
- Split the renderer into foundation, window-mode, Settings, Home/Search, and panel-bridge controllers. The entry file now only starts the application.

## Responsive and accessible layouts

- At 960×720, multi-column feature panels collapse to one column, action rows wrap, plugin names remain readable, and page-level horizontal scrolling is rejected.
- Added consistent keyboard focus, Tab navigation, Esc routing, and loading/success/error/disabled presentation without changing feature semantics.
- LiteSnap overlay, long-capture controller, selection popup, and selection guide now consume the shared theme variables and retain their existing capture lifecycle.

## Review and verification

- Added `pnpm run review:ui`, which generates non-committed 1440×900 and 960×720 screenshots plus an HTML index under `artifacts/ui-review/`.
- The UI audit checks horizontal overflow, clipped control text, focus visibility, shared theme tokens, and one non-default accent color.
- Source regressions, the complete Electron smoke suite, LiteSnap bidirectional long-capture flows, UTF-8 validation, and Windows package verification are release gates.
- A disposable in-place `v1.1.12 → v1.1.14` NSIS upgrade retained LiteSnap settings and history, the selected UI theme, and updater support.
- macOS artifacts remain unsigned; LiteSnap long capture remains Windows-only.
