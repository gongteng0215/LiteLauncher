# LiteLauncher v1.1.14 发布日志

发布日期：2026-08-13

## 全应用界面统一

- 建立共享的 4/8/12/16/24px 间距、8/12px 圆角、36px 控件、焦点环、禁用态、状态块、卡片、表单网格、工具栏和可见操作区。
- 首页、搜索、设置、全部插件、Cashflow、划词、词典、LiteSnap 和贴图窗口统一页面层级，同时保留现有暗色主题与强调色方向。
- 渲染层拆分为基础、窗口模式、设置、首页/搜索与面板桥接控制器，主入口只负责启动应用。

## 响应式与可访问性

- 960×720 下复杂功能面板切换为单栏，操作按钮可换行，插件名称完整可读，并禁止页面级横向滚动。
- 统一键盘焦点、Tab 顺序、Esc 路由以及加载、成功、错误和禁用状态，不改变功能语义。
- LiteSnap overlay、长截图控制条、划词弹窗与选区虚线框接入共享主题变量，截图生命周期保持不变。

## 审查与验证

- 新增 `pnpm run review:ui`，在 `artifacts/ui-review/` 下生成不提交仓库的 1440×900、960×720 截图和 HTML 索引。
- UI 审查自动检查横向溢出、控件文字裁切、焦点可见性、共享主题变量以及一个非默认强调色。
- 发布门禁包含源码回归、完整 Electron smoke、LiteSnap 双向长截图、UTF-8 编码检查和 Windows 安装包校验。
- 已在隔离临时目录完成 `v1.1.12 → v1.1.14` NSIS 原位升级，LiteSnap 设置与历史、界面主题和更新支持状态均正常保留。
- macOS 资产继续保持未签名说明；LiteSnap 长截图仍仅支持 Windows。
