# LiteLauncher v1.1.15

Released: 2026-08-17

## HTTP Mock lifecycle

- Added explicit starting, running, stopping, stopped, and error states to the local HTTP Mock Server.
- Repeating an unchanged start request now keeps the current listener and request count instead of restarting it.
- Port conflicts and permission failures leave the server stopped and show an actionable message; retrying after the conflict is removed works without restarting LiteLauncher.
- Added an internal plugin disposal hook so app exit closes the listener and immediately releases its port.

## Development process stability

- Added an independent local ownership lock to the Electron development runner while retaining the existing project-level `pnpm dev` lock.
- A newly started runner now asks an orphaned previous runner to close its Electron process tree before taking ownership, reducing duplicate processes and global-shortcut conflicts.
- Added a process-level regression that verifies clean lock handoff without launching Electron.
- The NSIS upgrade verifier now refuses ordinary local Windows sessions and requires an explicitly disposable environment, preventing release tests from replacing an installed copy.

## UI and verification

- UI review now checks rendered pages for suspicious mojibake in addition to horizontal overflow, clipped text, focus visibility, and theme tokens.
- Added 125% and 150% Electron renderer-scale smoke coverage for Home, Settings, HTTP Mock, and LiteSnap.
- Added HTTP Mock source and Electron regressions for conflicts, repeated starts, request handling, app exit, and port reuse.
- Verified an isolated in-place NSIS upgrade from v1.1.14 to v1.1.15; LiteSnap settings, history, theme, and updater state were retained.
- macOS artifacts remain unsigned; LiteSnap long capture remains Windows-only.
