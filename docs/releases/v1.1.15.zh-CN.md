# LiteLauncher v1.1.15 发布日志

发布日期：2026-08-17

## HTTP Mock 生命周期

- 本地 HTTP Mock Server 增加启动中、运行中、停止中、已停止和失败等明确状态。
- 相同配置重复启动时保留现有监听和请求计数，不再无条件重启服务。
- 端口占用或权限不足时保持未启动并展示可执行提示；冲突解除后可以直接重试，无需重启 LiteLauncher。
- 增加内部插件清理入口，退出应用时主动关闭监听并立即释放端口。

## 开发进程稳定性

- 在现有 `pnpm dev` 项目级互斥基础上，为 Electron 开发 runner 增加独立本地接管锁。
- 新 runner 发现孤立旧 runner 时，会先请求旧进程关闭其 Electron 进程树，再接管运行权，减少重复进程和全局快捷键冲突。
- 新增真实双进程锁接管回归，且测试过程不会启动 Electron。
- NSIS 升级验证增加一次性 Windows 环境硬门禁，普通本机会直接拒绝运行，避免发布测试替换已安装版本。

## 界面与验证

- UI 审查在横向溢出、文字裁切、焦点和主题变量检查之外，增加运行时疑似乱码检测。
- 新增首页、设置、HTTP Mock 和 LiteSnap 的 125%/150% Electron 渲染缩放 smoke。
- HTTP Mock 源码与 Electron 回归覆盖端口冲突、重复启动、请求命中、应用退出和端口复用。
- 已在隔离环境完成 v1.1.14 → v1.1.15 NSIS 原位升级验证，LiteSnap 设置、历史、主题和更新状态均成功保留。
- macOS 资产继续保持未签名说明；LiteSnap 长截图仍仅支持 Windows。
