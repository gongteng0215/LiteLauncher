# LiteLauncher v1.1.16

Released: 2026-08-17

## Cashflow review history

- Replaced the placeholder review with the 12 most recent active and archived games stored in SQLite.
- Added game switching, outcome and score summaries, cash/passive-income changes, peak net worth, decision counts, and a structured decision timeline.
- Review refresh now uses an internal side-effect-free command, and opening a completed game no longer starts a replacement game.

## Three offline AI personalities

- Expanded AI mode to three concurrent personalities: conservative, balanced, and growth-oriented.
- Each personality uses different risk, borrowing, cash-reserve, and ROI thresholds, so the same opportunity can produce different decisions.
- AI cards and reviews now show personality descriptions, recent actions, and human-readable decision reasons.
- Existing single-AI saves are upgraded in place by adding missing personalities without duplicates. No user-setting, public IPC, or database-schema migration is required.

## UI and verification

- Extended the local UI review to cover the normal Cashflow game, three-AI mode, and review history at 1440×900 and 960×720.
- Release validation covers source regressions, the complete Electron smoke suite, UTF-8 checks, and Windows NSIS/ZIP package verification.
- macOS assets remain unsigned; LiteSnap long capture remains Windows-only.
