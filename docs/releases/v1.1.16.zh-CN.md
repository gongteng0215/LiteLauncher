# LiteLauncher v1.1.16 发布日志

发布日期：2026-08-17

## Cashflow 最近对局复盘

- 将原复盘占位页升级为 SQLite 中最近 12 局活动和归档对局。
- 支持切换对局，并展示结果与评分、现金/被动收入变化、最高净资产、决策数量和结构化决策时间线。
- 复盘刷新改用无面板副作用的内部命令；打开已结束对局不会再自动新开一局。

## 三种离线 AI 性格

- AI 模式扩展为稳健、均衡、进取三种并行性格。
- 三种性格使用不同的风险、贷款、现金储备和 ROI 阈值，相同机会可以产生不同决策。
- AI 卡片和历史复盘会展示性格说明、最近动作和可读的决策原因。
- 旧单 AI 存档会自动补齐缺失性格且不会重复创建；不新增用户设置、公开 IPC 或数据库结构迁移。

## 界面与验证

- 本地 UI 审查新增 Cashflow 普通对局、三 AI 模式和历史复盘，覆盖 1440×900 与 960×720。
- 发布门禁覆盖源码回归、完整 Electron smoke、UTF-8 检查和 Windows NSIS/ZIP 打包校验。
- macOS 资产继续保持未签名说明；LiteSnap 长截图仍仅支持 Windows。
