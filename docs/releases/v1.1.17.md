# LiteLauncher v1.1.17

Released: 2026-08-21

## Independent widths for every LiteSnap tool

- Rectangle, ellipse, line, arrow, pen, highlighter, mosaic, and blur now remember separate 1–60 px widths.
- Switching tools in the capture toolbar immediately restores that tool's width and shows a contextual label such as “Arrow width 14”.
- LiteSnap settings now expose all eight defaults. The previous shared width is copied to every tool during the first upgrade load, preserving existing behavior.
- Text and numbered markers continue to use their independent font size and no longer show an irrelevant width slider.

## Long-capture reliability

- Fixed a focus-routing race where the transparent selection guide could intercept native Windows wheel input, resulting in one-frame captures or unreliable reverse scrolling.
- Native wheel input, cursor restoration, and guide focus changes now run in a stable order while preserving manual downward, upward, and return-to-bottom capture.
- Added an isolated real-Windows long-capture gate that verifies both ends, direction changes, and exclusion of the dashed selection guide from saved pixels.

## Update and long-term regression gates

- Added a read-only live update metadata verifier for the Latest Release, `latest.yml`, NSIS, blockmap, asset size, and release notes without downloading or executing an installer.
- Extended Cashflow coverage for repeated legacy single-AI hydration, persistence deduplication, frequent 14-game archival, the newest 12 reviews, and lifetime-stat retention.
- Release validation covers the complete source regression suite, Electron smoke suite, UTF-8 checks, and Windows NSIS/ZIP package verification.
- macOS assets remain unsigned; LiteSnap long capture remains Windows-only.
