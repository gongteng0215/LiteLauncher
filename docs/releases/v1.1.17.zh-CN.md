# LiteLauncher v1.1.17 发布日志

发布日期：2026-08-21

## LiteSnap 每工具独立粗细

- 矩形、椭圆、直线、箭头、画笔、荧光笔、马赛克和模糊现在分别记忆自己的 1–60 px 粗细。
- 在截图工具栏切换工具时会立即恢复对应粗细，并显示“箭头粗细 14”等当前工具提示。
- LiteSnap 设置页新增八种工具的独立默认粗细；旧版本保存的统一粗细会无损复制到全部工具。
- 文字和序号继续使用独立字号，不再显示无效的粗细滑条。

## 长截图与稳定性

- 修复透明选区窗口抢占焦点后，真实 Windows 滚轮可能只采集一帧或无法可靠反向滚动的问题。
- 原生滚轮、鼠标位置恢复和选区窗口焦点切换按稳定顺序处理，继续支持手动向下、向上和再次滚到底部。
- 新增真实 Windows 原生长截图回归入口，验证顶部、底部、方向切换和虚线框不会进入保存结果。

## 更新与长期回归

- 新增只读线上更新元数据校验，可检查 Latest Release、`latest.yml`、NSIS、blockmap、文件大小和发布说明，不下载或运行安装包。
- Cashflow 增加旧单 AI 多次水合/持久化去重、14 局频繁归档和最近 12 局复盘回归，确保长期累计统计不丢失。
- 发布门禁覆盖完整源码回归、完整 Electron smoke、UTF-8 检查和 Windows NSIS/ZIP 打包校验。
- macOS 资产继续保持未签名说明；LiteSnap 长截图仍仅支持 Windows。
