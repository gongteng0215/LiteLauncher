# LiteLauncher v1.1.18

Released: 2026-08-24

## Direct LiteSnap annotation editing

- Rectangles, ellipses, lines, arrows, pen strokes, highlights, text, and numbered markers remain selected after creation and can be moved or resized without switching to the Select tool.
- Dragging empty space continues drawing the active annotation type. Resizing changes geometry without scaling that tool's stored line width.
- Fixed overlapping box handles and added dedicated start/end handles for lines, arrows, and highlights.
- Selection and annotation handles now use smaller visible controls with larger transparent hit areas, reducing obstruction without making them hard to grab.
- Undo, redo, and delete controls now reflect their actual availability and identify deletion of the selected annotation.

## Reliable text input

- Text inputs now carry session tokens so a stale blur callback cannot close a newer editor.
- Clicking another blank point commits the current text and immediately opens the next input. IME composition is protected from premature blur commits.
- Double-click existing text in Select mode to edit it in place. Ctrl/Cmd+Enter commits, while Escape restores the original content.

## Whole-window F3 pin resizing

- Removed percentage controls, zoom buttons, and wheel zoom in favor of native Windows edge and corner resizing with the original aspect ratio locked.
- Fixed native resize and custom content drag firing together, which previously made the pin follow the pointer while resizing.
- Moving across displays, restoring the initial size, and DPI-aware bitmap refreshes preserve the image aspect ratio.
- Resizing is disabled while click-through is active and restored afterwards. Copy and save always use the original screenshot resolution.

## Compatibility

- No new user settings, database migrations, or public Launcher IPC channels are introduced. Existing LiteSnap settings and history remain compatible.
- macOS assets remain unsigned. LiteSnap long capture and this release's native F3 resize path are primarily validated on Windows.
