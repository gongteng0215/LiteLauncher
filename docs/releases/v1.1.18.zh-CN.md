# LiteLauncher v1.1.18 发布日志

发布日期：2026-08-24

## LiteSnap 标注直接编辑

- 方框、椭圆、直线、箭头、画笔、荧光笔、文字和序号画完后保持选中，可直接拖动对象或控制点，无需切换“选择”工具。
- 在空白处拖动仍会继续绘制当前类型；缩放只改变标注几何大小，不会意外放大对应工具的线宽。
- 修复八个控制点重叠，并为直线、箭头和荧光笔提供独立起点与终点控制点。
- 选区与标注控制点的可见尺寸缩小，同时保留更大的透明命中区，减少对截图内容的遮挡。
- 撤销、重做和删除按钮会同步当前真实状态；选中对象时明确显示“删除选中标注”。

## 文字输入稳定性

- 文字输入加入会话序号，旧输入框延迟到达的失焦事件不会关闭新的输入框。
- 点击选区内其他空白位置会提交当前文字并立即开始下一段，中文输入法组词期间不会被提前提交。
- 在选择模式下双击已有文字即可原位修改；Ctrl/Cmd+Enter 提交，Esc 恢复原内容。

## F3 贴图整体缩放

- 移除百分比、放大/缩小按钮和滚轮缩放，改为 Windows 原生四边与四角整体等比缩放。
- 修复边缘缩放与内容拖动同时触发导致贴图追随鼠标移动的问题；缩放边缘和内部移动现在互斥。
- 贴图跨屏、移动和恢复初始大小时保持原图比例，并在缩放结束后延迟重建适配当前 DPI 的显示位图。
- 点击穿透期间禁用缩放，退出穿透后恢复；复制和保存始终使用原始截图分辨率。

## 兼容性

- 不新增用户设置、数据库迁移或公开 Launcher IPC，现有 LiteSnap 设置和历史保持兼容。
- macOS 资产继续保持未签名说明；LiteSnap 长截图和本版 F3 原生缩放优化以 Windows 为主要验证平台。
