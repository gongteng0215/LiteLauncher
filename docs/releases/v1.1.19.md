# LiteLauncher v1.1.19

Released: 2026-08-28

## Stable F3 pin movement

- Pinned-image content drags now lock the window size captured at pointer-down, preventing Windows native resize frames from turning a move gesture into continuous enlargement.
- Native edge resizing is suspended only while content is being dragged and restored on pointer release, cancellation, or blur.
- Moving and resizing remain separate interactions, while copy and save continue to use the original screenshot resolution.

## More compact plugin workspaces

- JSON & CSV Lab now keeps conversion routes, examples, cleaning actions, and field extraction in compact selection controls on the same operation row.
- Removed the redundant structure preview so input and output editors receive more usable height.
- String casing, password presets, image-prompt style groups, Hardware Inspector export/copy actions, and Clipboard Workbench controls now use denser layouts without removing their existing capabilities.
- Responsive layouts continue to collapse safely at narrow desktop widths without page-level horizontal overflow.

## Theme and regression fixes

- Fixed inactive Cron quick-template and delete buttons falling back to a native white background; all states now follow the active dark theme.
- Fixed modern GPUs with more than 4 GB of VRAM being reported as 4 GB because the legacy WMI field is only 32-bit. Hardware Inspector now prefers the driver's 64-bit value, optionally falls back to NVIDIA's driver query, labels the source, and refuses to present a saturated WMI value as exact capacity.
- GPU resolution now explains when an adapter may not directly drive a display, which is common on hybrid-graphics laptops, instead of showing an unexplained unknown value.
- Added source and Electron coverage for compact panel layouts, Cron button surfaces, and the F3 move/resize interaction boundary.
- No user settings, database migrations, or public Launcher IPC channels are added in this release.

## Compatibility

- Windows NSIS remains the primary verified installer and auto-update path.
- macOS assets remain unsigned; LiteSnap long capture and native F3 behavior remain primarily validated on Windows.
