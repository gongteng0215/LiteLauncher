# LiteLauncher v1.1.19 发布日志

发布日期：2026-08-28

## F3 贴图移动稳定性

- 按住贴图内容开始拖动时锁定当前窗口宽高，避免 Windows 原生缩放帧与移动手势同时触发，导致图片持续放大。
- 仅在内容拖动期间暂停边缘缩放，并在松开、取消或失焦后恢复。
- 移动和缩放继续作为两种独立交互；复制与保存仍使用截图原始分辨率。

## 插件工作区紧凑化

- JSON & CSV 实验室将常用路线、快捷示例、清洗操作和字段提取收进紧凑选择控件，并排放在同一操作行。
- 移除重复占用空间的结构预览，把更多高度留给输入与输出编辑区。
- 字符串格式、密码预设、图片提示词风格、Hardware Inspector 导出/复制和 Clipboard Workbench 常用操作均改为更紧凑的布局，现有能力保持不变。
- 窄窗口下继续安全换行或转为单列，不产生页面级横向滚动。

## 主题与回归修复

- 修复 Cron 快捷模板未选中按钮和删除按钮回退成系统白色背景的问题，所有状态现在都遵循当前暗色主题。
- 修复现代显卡超过 4 GB 后仍被旧 WMI 32 位字段显示成 4 GB 的问题。Hardware Inspector 现在优先读取驱动 64 位容量，并以 NVIDIA 驱动查询作为可选回退；界面会标明数据来源，无法确认时不再把截断值当作准确容量。
- 混合显卡笔记本中的独显可能不直接连接屏幕；分辨率缺失时现在会明确说明这种情况，不再只显示含义不清的“未知”。
- 增加插件紧凑布局、Cron 按钮背景和 F3 移动/缩放边界的源码与 Electron 回归。
- 本版不新增用户设置、数据库迁移或公开 Launcher IPC。

## 兼容性

- Windows NSIS 继续作为主要验证的安装与自动更新路径。
- macOS 资产继续保持未签名说明；LiteSnap 长截图与原生 F3 行为仍以 Windows 为主要验证平台。
