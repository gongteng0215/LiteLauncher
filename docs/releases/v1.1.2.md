# LiteLauncher v1.1.2 Release Notes

Release date: 2026-07-24

## Highlights

Hotfix: after the first `Alt+Space` open and close, the launcher could not be shown again.

### Fixes

- Stop waiting on `requestAnimationFrame` while the window is hidden (it often never fires, so `show()` never ran).
- Show the window immediately on invoke; sync home state afterward.
- Force opacity back to 1 before hide so Windows can show the window again.

### Notes

- **v1.1.1 has been pulled** — do not download that build; use this release instead.
- Users on v1.1.0 can update in-app to v1.1.2.
- If you already installed broken v1.1.1, install this build over it.

## Suggested checks

1. `Alt+Space` → close → `Alt+Space` again; it should open every time.
2. Toggle repeatedly and confirm it does not hang.
