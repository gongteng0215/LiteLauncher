# LiteLauncher v1.1.2 发布日志

发布日期：2026-07-24

## 本版重点

紧急修复：`Alt+Space` 第一次可唤起，关闭后第二次无法再打开。

### 修复

- 隐藏窗口后再唤起时，不再等待隐藏态下的 `requestAnimationFrame`（该回调经常不会触发，导致 `show()` 卡住）。
- 显示路径改为先立即显示窗口，再异步同步主页状态。
- 隐藏前强制恢复不透明度，避免 Windows 上透明度为 0 时再次显示失败。

### 说明

- **v1.1.1 已下线**，请勿再下载该版本；请改用本版。
- 已安装 v1.1.0 的用户可通过应用内更新升到 v1.1.2。
- 若已装上有问题的 v1.1.1，请手动安装本版覆盖。

## 验证建议

1. `Alt+Space` 打开 → 关掉 → 再 `Alt+Space`，应每次都能打开。
2. 重复多次切换，确认不会卡死。
