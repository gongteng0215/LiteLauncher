# LiteLauncher v1.1.20

Released: 2026-09-04

## Accurate Hardware Inspector identification

- Added a fully offline vendor resolver that presents familiar Chinese brand names for Intel, Kingston, NVIDIA, GIGABYTE, Samsung, SK hynix, Micron, Western Digital, and other common vendors.
- Windows' original manufacturer values remain available in technical details. Disk brands inferred from explicit model prefixes are labeled as inferred, while memory vendors are never guessed from ambiguous models.
- GPU memory is now classified as verified dedicated memory, shared or dynamically allocated memory, an unverified driver-reported value, or an unreliable legacy WMI value.
- Displays are shown independently from graphics adapters with resolution, refresh rate, scale factor, and primary/extended-screen state.

## Staged collection and diagnostics

- Core CIM/SMBIOS queries use a 15-second operation timeout, optional GPU/storage/temperature queries use a 6-second operation timeout, and the complete collection is capped at 30 seconds.
- Optional-source failures return a partial result without discarding confirmed hardware data. A failed manual refresh keeps the previous snapshot visible.
- Added anonymous collection diagnostics with per-stage duration, source, status, and device counts, plus a one-click copy action in the More menu.
- Only terminal collection failures are persisted to the existing error log. Diagnostics and logs exclude user names, file paths, serial numbers, and PNP IDs.

## A clearer hardware workspace

- Six overview cards consistently show device, system, CPU, memory, graphics, and storage information, using three columns at both 1440px and 960px widths.
- CPU, memory, and GPU sections open by default; motherboard/BIOS, storage, displays, and diagnostics stay collapsed until needed.
- Matching memory modules are summarized first, such as `Kingston · 4×8 GB · DDR3-1600`, with individual slots available on demand.
- Serial numbers, PNP IDs, Processor IDs, and other low-level fields are hidden in technical details by default. Full JSON explicitly warns that it includes device identifiers.
- Replaced the permanent report-image sidebar with an on-demand modal that supports Escape, focus trapping, compact export, and full-length export.

## Compatibility and verification

- No user settings, database migrations, or public Launcher IPC channels are added; existing snapshot fields remain compatible.
- Windows verification covers real hardware collection, vendor and VRAM regressions, 1440×900 / 960×720 UI review, and a targeted Hardware Inspector Electron flow.
- macOS keeps its existing limited-collection notice and unsigned release policy.
