# LiteLauncher v1.1.20 发布日志

发布日期：2026-09-04

## Hardware Inspector 准确识别

- 新增完全离线的硬件厂商解析，主界面直接显示英特尔、金士顿、英伟达、技嘉、三星、海力士、美光、西部数据等常见中文品牌。
- 技术详情继续保留 Windows 原始厂商字段；磁盘只能由型号推断品牌时会明确标记“由型号识别”，内存不会根据模糊型号猜测厂商。
- 显存区分已验证独立显存、共享或动态内存、驱动报告值和旧 WMI 32 位截断值；无法确认的容量不再显示成准确值。
- 显示器从显卡信息中独立出来，展示当前分辨率、刷新率、缩放比例和主屏/扩展屏状态。

## 分阶段采集与诊断

- 核心 CIM/SMBIOS 查询使用 15 秒操作超时，可选 GPU、存储和温度查询使用 6 秒操作超时，整次采集最多等待 30 秒。
- 可选来源不可用时返回“部分完成”，保留已经确认的数据；手动刷新失败时继续显示上一次结果。
- 新增匿名检测诊断，展示各阶段耗时、数据来源、状态和设备数量，并可从“更多”菜单一键复制。
- 只有终态采集失败写入现有错误日志；诊断和日志不包含用户名、文件路径、序列号或 PNP ID。

## 更直观的硬件页面

- 顶部固定显示设备、系统、CPU、内存、显卡和存储六张概览卡，在 1440px 和 960px 下保持三列布局。
- CPU、内存和显卡默认展开；主板/BIOS、存储、显示器和检测诊断默认收起。
- 多条相同内存先汇总为“金士顿 · 4×8 GB · DDR3-1600”，再按需展开查看各插槽。
- 序列号、PNP ID、Processor ID 等信息默认收进技术详情；完整 JSON 会明确提示包含设备标识。
- 移除常驻报告图片侧栏，改为按需弹层预览，支持 Esc 关闭、焦点限制、紧凑图和完整长图导出。

## 兼容性与验证

- 不新增用户设置、数据库迁移或公开 Launcher IPC，原有硬件快照字段继续兼容。
- Windows 完成真实硬件采集、厂商与显存回归、1440×900 / 960×720 UI 审查和 Hardware Inspector Electron 测试。
- macOS 保持现有受限采集说明和未签名发布策略。
