# LiteLauncher v1.1.21 发布日志

发布日期：2026-09-16

## 长截图稳定性修复

- 修复长截图窗口反复置顶、滚动后抢走键盘焦点的问题。
- 支持选区内右键取消，并加强 Esc 退出；全局 Esc 被占用时仍可启动长截图。
- 控制窗口关闭、无响应或渲染进程异常时退出截图，不再自动重建窗口。
- 取消截图时优先释放鼠标和窗口，避免诊断记录等异步操作延迟退出。
- 原生截图改在工作线程执行并加入超时，降低底层截图阻塞主界面的风险。
- 启动失败显示具体原因，区分原生模块、截图画面和目标窗口问题。

## 构建与开发体验

- 更新 Windows 原生截图预编译模块，补齐长截图需要的接口。
- 构建时实际检查原生模块导出接口，拒绝发布不兼容模块。
- 修复 Electron 可执行文件缺失时开发脚本持续重试、刷屏的问题。
