# LiteLauncher v1.1.23

## 划词弹窗

- 修复点击外部偶尔无法关闭词典或翻译弹窗的问题，包括弹窗已经失去焦点的情况。
- Windows 使用临时鼠标观察处理外部点击，点击仍传递给原应用；弹窗关闭后立即停止观察。
- 修复外部点击备用遮罩的脚本加载与点击命中问题，保留关闭按钮和不自动关闭的设置。

## 截图贴图

- 修复不同屏幕缩放比例下，截图后直接贴图变小的问题，保留截图选区的显示尺寸。
- 修复贴图连续拖拽时尺寸逐渐放大或缩小的问题。

## 搜索与更新

- 新增搜索历史，可展开查看、再次搜索、删除单条或清空；最多保存最近 50 条，仅保存在本机。
- 修复从快捷入口打开应用或插件后，最近访问未及时刷新的问题。
- 设置中的更新状态自动刷新，下载时显示进度条，检查更新时显示等待状态。
- 将安装按钮放在更新说明前面，修复提示文字被挤成竖排的问题。
