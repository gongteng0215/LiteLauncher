# LiteLauncher v1.1.3 Release Notes

Release date: 2026-07-24

## Highlights

LiteSnap polish: WeChat-like toolbar placement, filled arrows, and smoother pin-window dragging.

### Improvements

- Capture toolbar prefers below the selection and flips above when space is tight; main tools stay on one row, with thickness/colors appearing only after an annotation tool is selected.
- Selection chrome and active tool states use the app violet accent.
- Arrows are drawn as a filled shaft + triangular head (WeChat-style).
- Selection edges can be resized; text annotations wrap automatically.

### Fixes

- Pinned images no longer stall or leave ghost trails while dragging (absolute drag origin instead of delta + `getBounds`).

## Suggested checks

1. Capture near the top/bottom of the screen and confirm the toolbar flips below ↔ above; selecting Arrow shows the style row.
2. Draw thin and thick arrows and confirm solid triangular heads.
3. Pin an image and drag it — motion should track the pointer without heavy afterimages.
