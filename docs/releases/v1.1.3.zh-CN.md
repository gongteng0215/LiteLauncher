# LiteLauncher v1.1.3 发布日志

发布日期：2026-07-24

## 本版重点

LiteSnap 体验对齐：工具栏更接近微信截图交互，贴图拖动不再卡顿留残影。

### 改进

- 截图工具栏：默认贴选区下方，空间不够翻到上方；主工具一行，选中标注工具后再出粗细/颜色第二行。
- 选区与工具选中态使用应用紫色系。
- 箭头改为微信式实心杆 + 三角箭头头。
- 选区支持边缘拖拽调整；文字标注支持自动换行。

### 修复

- 贴图（定住）拖动时不再因增量 `getBounds` 丢位移而拖不动，并减轻拖动残影。

## 验证建议

1. 截图框选靠顶/靠底，确认工具栏下↔上翻转；点箭头出现第二行样式。
2. 画粗细不同的箭头，确认是实心三角头。
3. 贴图后拖动窗口，应跟手且无明显残影。
