# LiteLauncher v1.1.4 Release Notes

Release date: 2026-07-25

## Highlights

LiteSnap annotation polish: radiating wedge arrows and freeform resize.

### Improvements

- Arrows are drawn as a full radiating wedge (tapers from a point, flares into a triangular head).
- Stroke size uses a continuous slider (2–24) instead of fixed presets.
- With the Select tool, selected annotations can be scaled by dragging resize handles.

## Suggested checks

1. Capture and draw arrows — confirm the radiating wedge shape.
2. Drag the width slider and confirm continuous size changes.
3. Switch to Select, click an arrow, and drag a corner handle to scale it.
