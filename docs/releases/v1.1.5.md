# LiteLauncher v1.1.5 Release Notes

Release date: 2026-08-04

## Highlights

LiteSnap annotation defaults and settings layout are now more reliable.

### Improvements

- The default annotation line width starts at 3 px and can be configured in LiteSnap settings.
- Line width accepts values from 1 to 60 px in both the settings panel and capture overlay.
- LiteSnap settings fields now use dedicated vertical cards, preventing labels and helper text from being compressed or clipped.

## Suggested checks

1. Open LiteSnap settings and set the default line width to 3, 24, or 60.
2. Start a capture and confirm the line-width slider respects the saved value and 1–60 range.
3. Confirm labels, inputs, and help text remain readable across the LiteSnap settings panel.
