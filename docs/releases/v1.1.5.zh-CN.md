# LiteLauncher v1.1.5 发布日志

发布日期：2026-08-04

## 本版重点

LiteSnap 标注默认值和设置页布局修复。

### 改进

- 标注线宽默认值调整为 3 px，并可在 LiteSnap 设置中自行保存。
- 设置页和截图覆盖层都支持 1–60 px 的线宽范围。
- LiteSnap 设置项改为专用纵向卡片，标签、输入框与说明文字不会再被挤压或裁切。

## 验证建议

1. 打开 LiteSnap 设置，将默认线宽设为 3、24 或 60。
2. 发起截图，确认线宽滑条读取保存的值，并可在 1–60 范围内调节。
3. 确认 LiteSnap 设置页的标签、输入框与说明文字均清晰可见。
