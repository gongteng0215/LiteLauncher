# LiteLauncher v1.1.6 Release Notes

Release date: 2026-08-05

## Highlights

Selection popup placement and dismissal are now more reliable.

### Fixes

- The cursor location is captured when the selection hotkey is pressed, so lookup or translation latency no longer moves the popup to a later cursor position.
- The outside-click backdrop now also closes the popup after a native focus transition that bypasses DOM pointer events.
- Command Center search results are supported by the Electron plugin-opening test helper, restoring dictionary panel smoke coverage.

## Suggested checks

1. Select a word, press the selection hotkey, move the mouse, and confirm the popup stays beside the original trigger point.
2. Click an empty area outside the popup and confirm it closes.
3. Search for the offline dictionary and confirm the plugin panel opens.
