# LiteLauncher v1.1.6 发布日志

发布日期：2026-08-05

## 本版重点

划词弹窗定位与关闭可靠性修复。

### 修复

- 按下划词快捷键时立即记录鼠标坐标，查词或翻译的延迟不会再让弹窗跳到之后的鼠标位置。
- 点击空白关闭层增加原生焦点兜底，部分未进入网页指针事件的 Windows 点击也会关闭弹窗。
- Electron 插件打开测试兼容 Command Center 搜索结果，恢复离线词典面板的 smoke 覆盖。

## 验证建议

1. 选中单词并按划词快捷键，再移动鼠标，确认弹窗仍显示在原触发位置附近。
2. 点击弹窗外空白区域，确认弹窗关闭。
3. 搜索“离线词典”，确认可正常打开词典插件面板。
