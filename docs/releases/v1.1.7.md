# LiteLauncher v1.1.7 Release Notes

Release date: 2026-08-05

## Highlights

Selection popups are easier to read at display edges, and LiteSnap restores the last drawing tool after an area is selected.

### Improvements

- Selection popups use a 420px layout with a scrollable body and fixed header/footer controls.
- Popups prefer the trigger point's lower-right quadrant and flip left/up at display edges, including negative-coordinate displays.
- Stale focus callbacks from an older selection request can no longer close or overwrite the newest popup.
- LiteSnap starts in selection mode for area creation, then restores the last non-selection annotation tool and keeps color, width, text size, and fill preferences.
- OCR settings now show Chinese and English engine readiness while retaining automatic Windows-local engine selection and missing-component installation guidance.
- Command Center dictionary smoke coverage now prioritizes the foreground search result over hidden background tiles.

## Suggested checks

1. Trigger a selection popup near a display edge and confirm it stays near the original point with readable content and controls.
2. Make a LiteSnap selection and confirm the previously used arrow, pen, or other drawing tool becomes active afterward.
3. Review OCR engine state in LiteSnap and confirm recognized text remains editable and copyable.
