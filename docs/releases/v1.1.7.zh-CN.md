# LiteLauncher v1.1.7 发布日志

发布日期：2026-08-05

## 本版重点

划词弹窗在屏幕边缘更易读，截图标注会在完成框选后恢复上次使用的工具。

### 改进

- 划词弹窗统一为 420px 宽；正文可滚动，标题和底部操作始终可见。
- 弹窗优先显示在触发点右下方，接近屏幕边缘时会自动翻到左侧或上方，多屏负坐标同样适用。
- 连续触发划词时，旧请求的失焦回调不会再关闭或覆盖最新弹窗。
- LiteSnap 每次仍先进入选择工具以便框选；选区建立后恢复上一次非选择标注工具，同时继续记住颜色、线宽、字号和填充状态。
- OCR 面板新增中文/英文引擎就绪状态，继续自动选择已安装的 Windows 本地 OCR 引擎，并只提示安装缺失组件。
- Command Center 下的词典 smoke 测试改为优先点击前景搜索结果，避免浮层遮住背景卡片。

## 验证建议

1. 在屏幕右下角附近按划词快捷键，确认弹窗翻转后仍靠近触发位置，正文和底部按钮均可见。
2. 先用 LiteSnap 框选区域，确认恢复上次的箭头、画笔等标注工具；新截图仍可以直接框选。
3. 在 LiteSnap 的 OCR 区查看中英文引擎状态，并使用“复制文字”确认识别结果可编辑复制。
