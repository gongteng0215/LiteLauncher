# LiteLauncher v1.1.8 发布日志

发布日期：2026-08-05

## 本版重点

自动更新失败现在会在设置页留下安全且可执行的诊断信息；更新或日志操作完成后，Command Center 的设置覆盖层会立即刷新，不再显示旧内容。

### 改进

- 主进程自动更新模块会把终态检查失败写入现有错误日志；同一次检查周期只记录一次。
- 更新日志包含阶段、当前版本和目标版本；失败详情会截断，并脱敏常见的令牌、授权、密码、密钥和 API Key 值。
- 「系统与更新」卡片新增「复制更新诊断」，会复制当前版本、目标版本、支持状态、最近阶段和诊断信息，便于反馈问题。
- 刷新/清空错误日志或检查更新后，会原地重绘当前设置覆盖层，界面内容与已保存状态保持同步。
- Electron 回归覆盖更新失败状态、错误日志落库、设置页刷新、诊断复制完整性和令牌脱敏。

### 发布验证

- 已执行完整 Electron smoke，并在本地生成 Windows x64 NSIS/ZIP 安装包。
- macOS 发布资产继续包含更新元数据；若缺少 Apple 签名凭据，发布会明确保持为未签名状态。

## 建议验证

1. 打开「设置 → 系统与更新」，点击「检查更新」；需要反馈时使用「复制更新诊断」。
2. 更新检查失败后，打开「设置 → 错误日志」，确认最新记录含阶段和版本上下文，且不包含访问凭据。
3. 请在可回收的测试环境中先安装 v1.1.7 Windows NSIS，再运行 v1.1.8 安装包，确认原位升级后应用数据符合预期。
