# LiteLauncher v1.1.9 Release Notes

Release date: 2026-08-10

## Highlights

LiteSnap now supports a complete Windows capture workflow: automatic vertical long capture, non-destructive editing from capture history, and safe performance diagnostics.

### Improvements

- Start a **Long capture** after selecting a scrollable region. LiteSnap scrolls down, verifies frame overlap before appending, and pauses instead of producing a misaligned image when matching is unreliable.
- The floating long-capture controller shows status, frame count, stitched height, and supports pause, resume, finish, and cancel. Safety limits cover target-window loss, unchanged frames, 120 frames, 120 seconds, and 30,000 px output height.
- Capture history items now include **Edit**. The original flattened PNG is always retained; copy, save, or pin from the editor creates a separate `history-edit` item.
- The editor keeps existing annotation tools, undo/redo and original-resolution export. Use Ctrl + mouse wheel to zoom and middle-mouse drag to pan while editing.
- The LiteSnap panel now includes **Performance diagnostics**, keeping the latest 20 anonymous operation records across restarts. Records contain timings and technical metrics only—never screenshots, file paths, OCR text, or clipboard contents.
- Terminal long-capture generation failures are deduplicated per session and written to the existing error log without screen content or file paths.

### Release validation

- Ran LiteSnap stitching and diagnostic persistence tests, the targeted LiteSnap Electron suite, and the complete Electron smoke suite before packaging.
- Produced Windows x64 NSIS/ZIP output locally. macOS assets retain the unsigned-release note when signing credentials are unavailable.

## Suggested checks

1. Select only the scrolling content area, choose **Long capture**, and use pause/resume/finish to confirm the final image opens in the existing editor.
2. Open **LiteSnap → Capture history → Edit**, add an annotation, then copy or save; confirm the source image remains and a new history item appears.
3. Open **LiteSnap → Performance diagnostics**, copy the report, then clear it. The output should contain metrics but no image data, file paths, OCR text, or clipboard content.
