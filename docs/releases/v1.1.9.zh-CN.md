# LiteLauncher v1.1.9 发布日志

发布日期：2026-08-10

## 本版重点

LiteSnap 现在覆盖完整的 Windows 截图流程：自动长截图、截图历史二次编辑，以及安全的性能诊断。

### 改进

- 框选滚动内容区域后可使用「长截图」。LiteSnap 自动向下滚动，并在确认相邻帧重叠可靠后才追加像素；匹配不可靠时会暂停，不会生成错位图片。
- 长截图浮动控制条实时展示状态、帧数和拼接高度，并支持暂停、继续、完成、取消。目标窗口失效、连续无新增内容、120 帧、120 秒和 30,000 px 高度均有安全保护。
- 截图历史新增「编辑」。原有扁平 PNG 永不覆盖；从编辑器复制、保存或贴图后，会新增来源为 `history-edit` 的历史项。
- 编辑器继续支持所有标注工具、撤销/重做和原图分辨率导出；按住 Ctrl 滚动鼠标滚轮缩放，中键拖动平移。
- LiteSnap 面板新增「性能诊断」，跨重启保留最近 20 条匿名操作指标。仅记录耗时和技术指标，不保存截图、文件路径、OCR 文本或剪贴板内容。
- 长截图生成失败会按单次会话去重写入既有错误日志；日志不含屏幕内容或文件路径。

### 发布验证

- 已执行 LiteSnap 拼接/诊断持久化测试、定向 LiteSnap Electron 回归和完整 Electron smoke，并完成 Windows x64 NSIS/ZIP 本地打包。
- macOS 资产继续保留未签名说明（无 Apple 签名凭据时）。

## 建议验证

1. 避开固定导航栏框选滚动内容，启动「长截图」，测试暂停/继续/完成后是否进入现有标注编辑器。
2. 打开「LiteSnap → 截图历史 → 编辑」，添加标注后复制或保存，确认原图仍在且新增一条历史记录。
3. 打开「LiteSnap → 性能诊断」，复制后清空；复制内容应只包含指标，不包含图片、路径、OCR 文本或剪贴板内容。
