# LiteLauncher 版本路线图（v1.1.3+）

更新时间：2026-07-24

当前线上版本：`v1.1.3`

## 规划原则

- 优先修复用户已经遇到的问题，再补体验，再做新增能力。
- 每一版保持「够用但不贪多」：一版最好围绕 2–4 个明确主题收口。
- 依赖 `dist` 产物的验证一律按「先 `pnpm run build`，再串行跑 `node dist/test/...`」执行。

## 已发布基线（v1.0.48 – v1.1.3）

## 下一版候选（v1.1.4+）

- SQLite 只读浏览助手
- Regex Explain / Cron 增强
- LiteSnap 长截图、标注二次编辑、性能诊断面板
- 更多 WebTools（OpenAPI 客户端、TLS 检查、批量请求等）
- Cashflow：AI 多性格、图表面板、教学模式
- 工程债：`renderer.ts` 继续瘦身、UI 文案巡检、E2E 扩展

## 明确后置

- Git LFS 托管词典（已由 Release 资产 + 按需下载替代）
