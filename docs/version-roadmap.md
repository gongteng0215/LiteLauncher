# LiteLauncher 版本路线图（v1.1.16+）

更新时间：2026-08-17

当前线上版本：`v1.1.16`

## 规划原则

- 优先修复用户已经遇到的问题，再补体验，再做新增能力。
- 每一版保持「够用但不贪多」：一版最好围绕 2–4 个明确主题收口。
- 依赖 `dist` 产物的验证一律按「先 `pnpm run build`，再串行跑 `node dist/test/...`」执行。

## v1.1.13–v1.1.14 已完成里程碑

### v1.1.13：模块化与稳定性基础

- 建立内部面板模块注册器和显式 `RendererPanelHost`，覆盖全部默认可见插件。
- 拆分 LiteSnap、CodeAgent、Cashflow、Hardware、Clipboard；兼容门面只保留模块分发和键盘路由。
- LiteSnap 抽离帧缓存、OCR、图片合成/导出、诊断与 overlay 生命周期服务，公开 IPC 保持不变。
- 本阶段保持视觉和操作等价，并作为 v1.1.14 工程基础一并交付。

### v1.1.14：全应用界面统一

- 其余 WebTools 按数据、网络安全、文本、媒体、开发者及词典翻译分组拆分。
- `renderer.ts` 拆分为设置、首页/搜索、窗口模式和面板桥接控制器。
- 使用统一间距、圆角、36px 控件、卡片、状态和操作区规范，960×720 下禁止页面级横向滚动。
- UI 审查脚本生成 1440×900、960×720 截图索引，并抽查非默认强调色。
- 截图、实际操作、完整 smoke、Windows 打包与原位升级均已通过发布门禁。

## 当前版本（v1.1.16）

主题：Cashflow 最近对局复盘与多性格离线 AI。

- `cash review` 读取 SQLite 中最近 12 局活动/归档对局，可切换查看结果、综合建议、现金与被动收入变化、最高净资产及结构化决策时间线。
- 复盘刷新改用无面板副作用的内部命令；查看已结束对局不再自动新开一局。
- AI 对战扩展为稳健、均衡、进取三种离线性格，分别使用不同风险、贷款、现金储备与 ROI 权重决策。
- 主面板和复盘均展示 AI 性格说明、最近决策和可解释原因；旧单 AI 存档自动补齐缺失性格且不会重复创建。
- 不新增用户设置、公开 IPC 或数据库迁移，现有 Cashflow 存档保持兼容。
- UI 审查覆盖 1440×900 与 960×720 下的普通对局、三 AI 卡片和复盘页。

- 最近 12 局复盘在长期使用和多次归档后的切换体验。
- 三种 AI 在相同机会下的决策差异与原因文案是否足够清晰。
