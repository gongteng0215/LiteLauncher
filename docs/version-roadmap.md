# LiteLauncher 版本路线图（v1.1.20+）

更新时间：2026-09-04

当前线上版本：`v1.1.20`

当前候选版本：无（等待下一批用户反馈）

## 规划原则

- 优先修复用户已经遇到的问题，再补体验，再做新增能力。
- 每一版保持「够用但不贪多」：一版最好围绕 2–4 个明确主题收口。
- 依赖 `dist` 产物的验证一律按「先 `pnpm run build`，再串行跑 `node dist/test/...`」执行。

## v1.1.13–v1.1.14 已完成里程碑

### v1.1.13：模块化与稳定性基础

- 建立内部面板模块注册器和显式 `RendererPanelHost`，覆盖全部默认可见插件。
- 拆分 LiteSnap、CodeAgent、Cashflow、Hardware、Clipboard；兼容门面只保留模块分发和键盘路由。
- LiteSnap 抽离帧缓存、OCR、图片合成/导出、诊断与 overlay 生命周期服务，公开 IPC 保持不变。
- 本阶段保持视觉和操作等价，并作为 v1.1.14 工程基础一并交付。

### v1.1.14：全应用界面统一

- 其余 WebTools 按数据、网络安全、文本、媒体、开发者及词典翻译分组拆分。
- `renderer.ts` 拆分为设置、首页/搜索、窗口模式和面板桥接控制器。
- 使用统一间距、圆角、36px 控件、卡片、状态和操作区规范，960×720 下禁止页面级横向滚动。
- UI 审查脚本生成 1440×900、960×720 截图索引，并抽查非默认强调色。
- 截图、实际操作、完整 smoke、Windows 打包与原位升级均已通过发布门禁。

## 上一版本（v1.1.19）

- F3 贴图移动期间锁定当前窗口尺寸，避免拖动与 Windows 原生缩放同时触发。
- JSON/CSV 等复杂插件的操作区改为紧凑选择控件，Cron 模板按钮补齐暗色主题。
- Hardware Inspector 优先使用驱动 64 位数据，不再把旧 WMI 4 GB 上限当作准确显存。

## 明确后置

- 大规模 UI 框架迁移 / 搜索算法重写
- Git LFS 托管词典（已由 Release 资产 + 按需下载替代）

## 当前版本（v1.1.20）

- Hardware Inspector 使用离线厂商解析器，将 GenuineIntel、Kingston、NVIDIA 等原始字段显示为英特尔、金士顿、英伟达等直观品牌名，原始值保留在技术详情。
- 显存区分已验证独显、共享/动态内存、未验证驱动报告值和旧 WMI 截断值；显示器信息独立展示。
- 核心、GPU、存储、显示器和温度阶段提供匿名状态与耗时诊断，可一键复制；刷新失败继续保留旧快照。
- 页面改为六张概览卡、核心硬件默认展开、敏感标识默认收起、内存按规格汇总和按需报告预览弹层。
- 不新增用户设置、数据库迁移或公开 Launcher IPC。

## 发布后观察

- 不同 OEM、内存、显卡和磁盘厂商原始字段的离线别名覆盖。
- NVIDIA/AMD 独显、Intel/AMD 集显及双显卡笔记本的显存类别和验证来源。
- 可选 CIM 数据源超时或缺失时“部分完成”的诊断准确性。
- `v1.1.19` 客户端发现 `v1.1.20`、加载发布说明并完成下载的线上元数据状态。
