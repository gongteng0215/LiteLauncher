# LiteLauncher 版本路线图（v1.1.19+）

更新时间：2026-08-28

当前线上版本：`v1.1.19`

## 规划原则

- 优先修复用户已经遇到的问题，再补体验，再做新增能力。
- 每一版保持「够用但不贪多」：一版最好围绕 2–4 个明确主题收口。
- 依赖 `dist` 产物的验证一律按「先 `pnpm run build`，再串行跑 `node dist/test/...`」执行。

## v1.1.13–v1.1.14 已完成里程碑

### v1.1.13：模块化与稳定性基础

- 建立内部面板模块注册器和显式 `RendererPanelHost`，覆盖全部默认可见插件。
- 拆分 LiteSnap、CodeAgent、Cashflow、Hardware、Clipboard；兼容门面只保留模块分发和键盘路由。
- LiteSnap 抽离帧缓存、OCR、图片合成/导出、诊断与 overlay 生命周期服务，公开 IPC 保持不变。
- 本阶段保持视觉和操作等价，并作为 v1.1.14 工程基础一并交付。

### v1.1.14：全应用界面统一

- 其余 WebTools 按数据、网络安全、文本、媒体、开发者及词典翻译分组拆分。
- `renderer.ts` 拆分为设置、首页/搜索、窗口模式和面板桥接控制器。
- 使用统一间距、圆角、36px 控件、卡片、状态和操作区规范，960×720 下禁止页面级横向滚动。
- UI 审查脚本生成 1440×900、960×720 截图索引，并抽查非默认强调色。
- 截图、实际操作、完整 smoke、Windows 打包与原位升级均已通过发布门禁。

## 上一版本（v1.1.18）

- 方框、椭圆、直线、箭头、画笔、荧光笔、文字和序号创建后可直接移动或缩放，控制点保持较小可见尺寸与较大透明命中区。
- 文字输入加入会话令牌与中文输入法组合态保护，并支持双击原位重编辑。
- F3 贴图改为 Windows 原生四边/四角整体等比缩放，复制和保存始终保留原分辨率。

## 明确后置

- 大规模 UI 框架迁移 / 搜索算法重写
- Git LFS 托管词典（已由 Release 资产 + 按需下载替代）

## 当前版本（v1.1.19）

- F3 贴图内容拖动开始时锁定当前宽高，并临时关闭原生缩放边框，避免移动手势与 Windows 缩放同时触发导致图片持续放大。
- JSON/CSV 实验室移除占空间的结构预览，将常用路线、示例、清洗和字段提取压缩到同一操作行，给输入与结果编辑区留出更多高度。
- 字符串格式、密码预设、图片提示词风格、Hardware Inspector 导出/复制和 Clipboard Workbench 常用操作统一为紧凑选择控件。
- Cron 快捷模板的未选中按钮和删除按钮补齐暗色主题，不再回退成系统白色按钮。
- Hardware Inspector 不再把 32 位 WMI 的约 4 GB 上限当作真实显存；优先读取驱动 64 位容量，并展示显存来源与混合显卡未直连屏幕说明。

## 发布后观察

- F3 在不同 DPI 和跨屏场景下连续执行“移动 → 缩放 → 再移动”时的尺寸稳定性。
- 不同厂商独显、集显和混合显卡环境中的显存来源与显示输出关联。
- JSON/CSV 字段下拉在大字段集合、窄窗口和键盘 Esc 关闭时的体验。
- 各插件紧凑操作区在 960×720 下的换行、焦点和文本完整性。
- `v1.1.18` 客户端发现 `v1.1.19`、加载发布说明并完成下载的线上元数据状态。
